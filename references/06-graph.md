# 调和一层

某一深度的每个节点都关闭后，先调和这一层再开下一层。图真正生长就在这里：选项变成节点、线合并、追与不追的记录落笔。

一个协调人跑整个 run：逐节点做计划，且只有它调和一层——因为只有它同时看得见每个已完成节点。节点自己的研究发生在其研究员的独立上下文；规划与写作留在你这里。

## 四件事

### 1. 把选项开成节点

每个待决选项得到归宿。

- **不同节点问同一问题的选项合到一个节点。**该节点以它们各自的节点为父；没人把问题研究两遍。
- **同名不是同题。**两个标签相像而前提不同的选项——同名之下对关键概念持不同定义的两种读法——是不同的可能，各开各的节点。
- **新节点的问题写成可规划的问句**，不是选项标签。

### 2. 决定什么不开

一个选项只有**结构性**理由才能不开：

- 它补充一个已存在或现在开的节点——点名那个节点；
- 已有节点在追它——点名那个节点；
- 它是更正而非可能；
- 深度限制挡住它；
- 节点预算挡住它——那么开理由最重的那些，其余记录在案。

把理由记入 `not_pursued`。**"不值得"不是理由**；真实的可能要么开出，要么把限制写明。

### 3. 汇合走到同一处的线

路径抵达同一处——同一状态、同一子问题、殊途同归的同一发现——的已完成节点，可以作为**汇合（join）**一起带向前：一个以它们各自为父的新节点。

- 汇合**共享它们此后的工作**；它们的历史、证据、前提各归各。
- 汇合**可以再分叉**。
- **结论一致不是汇合的理由。**改记 `converge`——独立路径达成一致本身就是发现，汇合它们会毁掉独立性的证据。
- **在诠释性与哲学性工作里，汇合是对峙。**能扬弃的扬弃，不能的把分歧划清。绝不平均。

### 4. 记录关系

run 内任意节点之间：

| 关系 | 含义 |
|---|---|
| `converge` | 独立路径抵达同一发现 |
| `diverge` | 在某个前提上分开、且保持分开的路径 |
| `resonates` | 论证可用、互不吞并的亲缘 |
| `appropriates` | 一条线为自己的目的取用另一条线的材料 |
| `displaces` | 一条线的叙述使另一条变得不必要或过时 |

关系**不调度任何东西**。终稿读它们；图不对它们做反应。

## 调和怎么记

`run.json` 持有四张清单。每项都被 `scripts/check.py` 校验；完整 schema 见 `references/09-ledger.md`。

### 选项开成节点

每条新研究线加一个节点，并把每个待决选项的 `node` 指向它。命令行：

```bash
python3 "$SKILL_DIR/scripts/node.py" <project> fork --node n_a1b2 --option o2 \
        --question "敕令把殖民卫生范畴移植进国内行政了吗？"
```

它会检查深度与节点预算、拒绝"一个可能开两次"（该选项已由别的节点在追时报错）、建好
节点目录与骨架文件，并把选项的 `node` 指过去。

```json
{
  "id": "n_new1",
  "folder": "05-colonial-repertoire",
  "seq": 5,
  "depth": 1,
  "kind": "line",
  "question": "敕令把殖民卫生范畴移植进国内行政了吗？",
  "parents": ["n_a1b2", "n_c3d4"],
  "opened_by": {"decision": "d1", "option": "o2"},
  "status": "queued",
  "cards": [],
  "synthesis": null,
  "synthesis_versions": 0,
  "review_rounds": 0,
  "dissolves": null,
  "issues": [],
  "gaps": []
}
```

合并问同一问题的两个选项：只记一个节点，`opened_by` 里写两个选项 id 不够——节点记一次，然后把**每个**选项的 `node` 都指向它。`check.py` 只在选项的 `node` 指向真实节点时认它已被追。

### 选项不开

```json
{"option": "o9", "reason": "节点预算已用尽：30/30。此选项按利害排序最低。"}
```

### 汇合已完成的线

```json
{"id": "n_join1", "parents": ["n_e5f6", "n_g7h8"],
 "question": "若财政与殖民两种叙述都成立，日本公共卫生行政的分期该怎样改写？",
 "rationale": "两线经不同路径都把 1919 年定为断裂；一起带向前是对峙，不是合并。"}
```

```bash
python3 "$SKILL_DIR/scripts/node.py" <project> join --parents n_e5f6,n_g7h8 \
        --question "若财政与殖民两种叙述都成立，日本公共卫生行政的分期该怎样改写？" \
        --rationale "两线经不同路径都把 1919 年定为断裂；一起带向前是对峙，不是合并。"
```

汇合节点也进 `nodes`，`"kind": "join"`、双亲齐全。少于两个父节点的汇合会被拒绝；父节点
还没终态会给警告（汇合应在父节点都完成后开）。

### 记录关系

```json
{"kind": "converge", "nodes": ["n_e5f6", "n_g7h8"],
 "note": "两线从独立证据把断裂定在 1919。"}
```

命令行记法：`python3 "$SKILL_DIR/scripts/node.py" <project> relation --kind converge --nodes n_e5f6,n_g7h8 --note "…"`。
`note` 可选——缺了 `graph.md` 里只剩类型，读者看不出两线共享什么，所以建议写。

然后从 `run.json` 重写 `graph.md` 与 `paths.md`（`python3 ${SKILL_DIR}/scripts/scaffold.py <project> --resume` 干的就是这件事）。

## 校验器强制的不变量

对照 `scripts/check.py`；每条对应一个 P0 或 P1。

- 选项 id 全 run 唯一；其决策 ≥2 选项、至多一个 `own`。
- 每个选项恰好一个归宿：`node`、`reason` 或 `covered_by`。两个并存是 P0。
- 选项的 `node` 与 `covered_by` 指向存在的节点。
- `reason` 必须点名一个约束。"不值得"及其各种说法会被拒——真实的可能要么开出，要么写明拦住它的限制。
- 节点 `depth` 恰好比其父的最大深度多一，不等于不小于、不超 `limits.depth`。
- 父节点存在；图无环；depth 0 恰有一个节点。
- 汇合 ≥2 个父、全部完成、有问题。
- 关系点名 ≥2 个存在节点、五种之一。
- 勘误点名存在节点。
- `declined[].reason` 必须点名约束，且 `issue_id` 指向本 run 已知的提案或选项。
- `cost` 若存在，其 `tokens` / `calls` / `usd` 必须是非负数，`entries[].node` 必须指向本 run 的节点。

节点预算与深度不再只是事后检查：`check.py` 会在在飞节点数超 `limits.parallel`、某节点派卡数
超 `limits.cards`、以及"每个在飞节点都分叉一次就会超 `max_nodes`"时点名提醒——预算是执行时
的承诺，不是事后才发现的事故。

它**不**查：汇合是否有据、两个选项是否真问同一问题、关系是否贴切。那些是判断；校验器只保证记录一致到读者之后能判断。

## 什么都不做的调和是合法的

没有分叉、汇合、关系可记时，记一次空调和并附摘要说明。不要为显得有产出而制造结构——编造的汇合比缺失的更糟，因为终稿会把它当作真实对峙。

## 调和之前

读结论，不只读摘要。联系两个节点的是**它们的结论说了什么**，不是它们是否互相点名。从未提及彼此的两节点可以 converge；互相引用的可以 diverge。

结论很长时逐节读而不是扫读：关系通常藏在保留意见里，不在论点句里。

## 禁止

- 为某个已有节点在追的前提选项开新节点。
- 因为结论一致而汇合节点。
- 在汇合中平均两个父节点的立场。
- 把"不值得"记成理由。
- 复用节点 id，或同一问题换名开两次。
- 本层还有节点在跑时就调和本层。
