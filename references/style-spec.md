# 绘图规范（完整版）

SKILL.md 里给的是高频值，这里给判定边界。两者冲突时以本文为准；本文与模板实测属性（坐标、画布尺寸、fill-opacity）冲突时，**模板优先**（模板取自 150 张仿绘成品，见 [template-catalog.md](template-catalog.md) 的"已知偏差"）。

## 1. 画布

| 项 | 规定 | 说明 |
|---|---|---|
| 背景 | `#FFFFFF` 纯白 | 不放渐变、纹理、水印 |
| 尺寸 | 宽高按原图比例取整到 8 的倍数 | 常用 1200×800、1000×700、1400×500、1200×640、900×900 |
| 留白 | 四边 ≥40px | 有引线标签的一侧按标签宽度再放宽 |
| 网格 | 8px | `lint_svg.py --grid` 可统计偏差 |
| 图题 | 不画进图内 | 图题由论文排版或图注系统添加；图内出现「图 1」会被 lint 判黄 |

竖长图（多阶段纵向流程）允许 1120×1232 这类非标准比例，但同样遵守 8px 网格与 40px 边距。

## 2. 字体

| 项 | 值 |
|---|---|
| 中文 | `Noto Sans CJK SC`（思源黑体） |
| 声明位置 | 根 `<svg font-family="Noto Sans CJK SC, sans-serif">`，只写一次 |
| 西文/数字 | 同字体回退，不单独指定 |
| 粗体 | `font-weight="700"`，不用 `font-style="italic"` 做强调（中文斜体观感差） |

字号阶梯：

| 用途 | 字号 | 字重 |
|---|---|---|
| 栏头 / 分面标题 | 16 | 700 |
| 阶段标题条 / 中心主题 | 15–17 | 700 |
| 模块标题 | 14–15 | 700 |
| 框内正文 | 13 | 400 |
| 次要说明 / 括号内英文 | 12 | 400 |
| 注释 / 引线标签 / 假设编号 | 11 | 400 |

字号不超过 3 档同时出现在一张图里（16 / 13 / 11 是最稳的三档）。同一层级的模块必须同字号。

**字号与框体的关系**：单行文字时，框高 ≥ 字号 × 3；两行时框高 ≥ 字号 × 5。框高 72 配 13px 正文是模板的通用比例。

## 3. 配色

| 语义 | 主色 | 浅底 | 用在哪 |
|---|---|---|---|
| 核心/主结构 | `#2F6BB0` | `#EEF4FB` | 核心模块、主干流程、阶段标题条 |
| 次级/一般模块 | `#4A86C5` | `#F4F8FD` | 一般模块、次级流程 |
| 强调橙 | `#E8833A` | `#FDF3EA` | 关键节点、输出、需要读者注意的一处 |
| 结果绿 | `#3E9B6C` | `#EDF7F2` | 结果/成效/终点 |
| 警示红 | `#C94F44` | `#FBF0EF` | 问题、约束、风险 |
| 中性灰 | `#8A94A6` | `#F3F5F8` | 背景带、注释框、辅助信息 |
| 语义紫 | `#7B5EA7` | — | 原图用紫色表示独立阶段时映射用，非通用色 |
| 连线 | `#5A6B7E` | — | 默认箭头与连接线 |
| 文字 | `#1A1A1A` | — | 正文；注释用 `#666666` |

规则：

- **每张图主色 ≤4 种**；同层同色，不同层用同色系深浅或不同语义色区分。
- 大面积分组底板用 `fill-opacity` 而不是实色：主色 `0.06`、绿色 `0.07`、灰色 `0.08`（TP01 层带实测 0.08，分组可读性优先）；灰色虚线分组框可用 `0.6` 不透明度。
- **深底反白**：`fill="#2F6BB0" fill-opacity="1"` 时文字必须 `#FFFFFF`；深底块一图不超过 3 个，否则抢视线。
- 原图五彩（紫/红/绿/蓝弧线）时按语义映射到本表，而不是照抄原色；保留"颜色区分阶段"的意图即可。
- 调色板外颜色会被 lint 记为 INFO，不是错误——期刊指定色、原图有必须保留的标识色时可以用，但要在图注里能说清。

## 4. 形状

| 图元 | 参数 | 语义 |
|---|---|---|
| 普通模块框 | `rx=6`，stroke 1.5，浅底 + 主色描边 | 标准模块 |
| 强调框 | `rx=6`，stroke 2；可加 6px 左侧色条 | 核心模块/当前阶段 |
| 概念/状态节点 | 圆或椭圆，stroke 1.5 | 循环节点、状态、中心主题 |
| 虚线框 | `stroke-dasharray="6 3"` | 可选、外部、边界、待定 |
| 背景分组带 | `rx=10`，浅色 + `fill-opacity 0.06–0.08`，组名放带内左上角（`x=带.x+24`，基线 `带.y+32`） | 一层、一个阶段、一个部门 |
| 胶囊/药丸 | `rx=高/2`（如 152 高配 `rx=76`） | 横向贯穿的流程条 |
| 梯形 | `<path>` 手写四点 | 金字塔层、漏斗层、底座 |
| 块箭头 | `<path>` 七点，白色填充 + 主色描边 | 支撑/上升流，不要滥用 |

分组带与成员框间距 **≥12px**（lint：<12 判黄，<8 判红）；带内模块顶边 `带.y + 56` 是公式缺省，各模板实测不同（如 TP01 为 +16），套模板以实测坐标为准。

## 5. 线

| 类型 | 参数 | 语义 |
|---|---|---|
| 实线箭头 | stroke 1.5，`marker-end` | 直接影响、主流程、数据流 |
| 虚线箭头 | `stroke-dasharray="5 4"` | 弱关联、反馈、间接影响 |
| 无箭头关联线 | 1.2–1.3，灰 | 纯并列/归属关系（如 T06 左右面板） |
| 双向 | marker 两端 | 相互影响、互动 |
| 正交折线 | `<path d="M.. H.. V..">`，`fill="none"` | 优先使用；拐点对齐元素中线 |
| 斜线 | 仅限"作用于"语义的短箭头 | 不许穿越其他模块 |

marker 统一几何（全库通用）：

```xml
<marker id="arrow" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7"
        orient="auto-start-reverse">
  <path d="M0,0 L10,5 L0,10 z" fill="#5A6B7E"/>
</marker>
```

按颜色建多个 marker（`arrow`/`arrowBlue`/`arrowOrange`…），`fill` 与线色一致。三角形边长 7px 配 1.5px 线宽最协调。

**零长度线段绝对不能带 marker**：`M336,96 V96` 这类路径多数渲染器不画箭头，会静默丢线。lint 判 FAIL。

## 6. 文字排版

| 项 | 规则 |
|---|---|
| 单行居中 | 基线 `y = 框.y + 框.h/2 + 0.35×字号` |
| 两行 | 两行基线以中心对称，行距 ≥1.5×字号（实践中 24–28px 配 13px 字最稳） |
| 文本宽度 | 中文/全角 1.0×；大写字母 0.72×（W/M 0.9×）；小写与数字 0.55×；空格 0.3×；中文字串里的歧义宽字符（`·`、希腊字母）按 1.0× |
| 换行阈值 | 超过框宽 90% 必须换行；换行点在词/短语边界 |
| 中英混排 | 中文一行、英文括号一行，英文可降 1–2px 并用 `#666666` |
| 竖排 | 逐字 `<tspan>`，字距 = 字号 + 2px；或 `transform="rotate(-90 x y)"` |
| 编号前缀 | `①②③` 或 `(1)(2)` 与原文一致，不混用两套 |
| 假设标签 | `H1`/`H2` 11px，放箭头中点上方 4px |

行距 <1.4×字号 lint 判 WARN；<1.2× 视为必然压字，必须改。

## 7. 边界情况

- **原图是统计图/照片/纯表格**：不硬仿。按图题的语义生成一个规范框式框架（总—分或阶段链），并在交付说明里写"原图非架构图，按题名语义重构"。
- **原图元件级电路图**：按"结构还原"简化成变换器框 + 母线 + 标签 + 流向，不逐符号复刻；电压/型号等标注全部保留。
- **原图方向**：层级自上而下、流程自左向右，与原图一致，不擅自翻转。
- **同一篇论文多张图**：共用一套配色映射，第二张图不要换主色。
- **图内需要图例**：图例框放右下角，`rx=6`，11px，只列颜色语义，不解释结构。
- **期刊要 EPS/PDF/TIFF 直投**：多数期刊不收 SVG 原文件——先自转（`cairosvg svg2pdf`、Inkscape 导 EPS/PDF），位图导出 ≥300 dpi（`render_svg.py --scale 4` 起步），可编辑源码随稿备改。
