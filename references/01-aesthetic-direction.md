# 01 · 审美方向与反模板

> 这一层决定「长什么样」。规则层（02–08）决定「必须遵守什么」；动效层（09/22）决定「变化怎么发生」。
> 审美不是形容词的堆叠，而是**可指认的选择**：为什么是这个结构、这个字、这个色、这个动。

## 立场

把自己当作一家设计工作室的设计负责人。工作室以「每个客户都有不会被认错的视觉身份」著称；
客户已经拒绝了几版「感觉像模板」的方案，并且在为**观点**付费，不是为像素付费。

所以：对结构、字体、配色、动效做出**刻意的、有主张的选择**，并且这些选择必须来自这个具体项目。
如果一份方案换个品牌名也成立，它就是模板。

## 审美高度的四个判据

| 判据 | 问法 | 不及格的样子 |
|---|---|---|
| **有根据** Grounded | 这个选择来自题材的哪个具体事实？ | 来自「现代」「简洁」「高级」这类形容词 |
| **有结构** Structural | 它是否决定了信息如何被读、被排、被操作？ | 只是贴在表面的装饰层 |
| **有主张** Opinionated | 它敢不敢放弃另一种同样合理的选择？ | 什么风格都沾一点，什么都不得罪 |
| **有完成度** Finished | 边缘、光学对齐、节奏、空状态是否都收口？ | 首屏精致，往下是默认组件堆叠 |

四条里缺一条，页面就会「看起来像生成的」。完成度是最容易被低估的一条：
多数业余页面不是配色错，而是**边缘没有收口**——卡片间距不齐、标题与正文光学不对齐、
最后一屏草率、移动端只是桌面缩小版。

## 签名方法：物性优先 Physical First

写布局之前，先选**一个物理关系**；布局是它的投影，动效是它的证据。

这不是比喻比赛。物理关系必须能回答三件事：

1. **内容如何被组织**：什么在中心，什么在轨道，什么在队列里，什么被折叠。
2. **交互如何发生**：拖动改变角度？滚动推进相位？按压触发开关？指针靠近产生磁吸？
3. **状态如何结束**：停在哪、回到哪、哪一帧是终态。

### 六步

1. **题材考古**（10 分钟）
   写下 3 个具体名词、2 种材料、1 个动词。必须是这个题材独有的。
   - 建筑事务所：剖面图、模型照片、场地坐标、混凝土、氧化铜、*推敲*。
   - 音频工具：波形、轨道、增益、铝、哑光黑、*对齐*。
   - 独立杂志：栏宽、首字下沉、纸张克重、riso 油墨、*折页*。
   不要写「创新」「赋能」「现代」「极简」。

   **材质取色**：先写材料，再从材料取底色。回收毛毡是灰绿而不是奶油；氧化铜是
   `#A63C25` 而不是陶土；哑光铝是冷灰而不是米白。如果第一反应是「奶油底 + 衬线 +
   陶土强调」，先停：那是默认，不是材料。只有在题材真的是纸张/印刷/暖光时才用它，
   并写下为什么。

2. **选一个物理关系**
   从 12 个里选，或自己造一个能一句话说清、能用 CSS/Canvas/WebGL 实现的：
   轨道 / 传送带 / 幕布 / 扫描头 / 镜头 / 剖面 / 折页 / 网格纸 / 转台 / 开关板 / 织机 / 档案柜。
   一个页面只允许**一个主结构**。不要 hero 做轨道、feature 做传送带、footer 做幕布。

   **物理关系不是「画一张图」，是让页面行为像它**：剖面页的滚动就是剖切位置，
   轨道页的拖拽就是转动，传送带页的滚动就是速度。只画一张剖面图、页面仍是
   「标题 + 三列卡片」，不算。

   **首屏必须是题材里最有特征的东西**，不是 masthead + 目录 + 封面图的杂志套件。
   如果题材是「走一条长路线」，首屏就该让人看见路线/高程/里程，而不是一张标题封面。

   **但图表不是英雄。** 一个全屏的灰色高程图/剖面图只「测量」题材，不「呈现」题材；
   它会变成仪表盘。首屏需要三件事同时在场：一个主导的排版陈述、一个人性细节
   （日期、地点、手写注记、材料样本、一张小图）、图表/剖面作为支撑。
   如果首屏只有图表和标题，回退到「图表 + 人」的组合，不要让图表独占一屏。

3. **写出三个布局推论**
   物理关系不是氛围词，必须推出布局：
   - 轨道 → 中心固定、项目绕行、深度同时改大小/模糊/叠放/亮度；
   - 传送带 → 水平无限、速度是主状态、边界有摩擦；
   - 剖面 → 垂直切片、标注在侧、滚动是剖切位置；
   - 幕布 → 全屏遮罩、揭开的边缘是唯一动效、内容在幕后分层。

4. **选一个注意瞬间**
   全页只允许一个非用户触发的主动效。其余动效只解释变化。
   这个瞬间必须来自物理关系本身：轨道开始转、幕布揭开、扫描头扫过、传送带启动。

   **注意瞬间必须在首屏可见或可感知**。如果它发生在第三屏以后，它就不是「这个页面的
   注意瞬间」，只是页尾的一个效果。首屏至少要让读者看到它的起点/因果线索
   （一条未展开的线、一个未对齐的切口、一个未启动的轨道）。

   交付时附**两帧截图**（起点/终点）或 3 秒录屏；只有静态首屏、没有动效证据，
   按 `verified: false` 处理。

5. **反默认复查**
   把方案与第 8 节的 AI 默认指纹逐条对照。命中任何一条，改那个轴，并写下改了什么、为什么。
   不是「避免用奶油色」，而是「奶油色在这个题材里没有依据，换成纸张样本的灰白」。

6. **截图自评**
   1280 与 375 各截一次。问四个问题：第一眼看到什么？第二眼在哪停？边缘有没有毛？
   摘掉一件配饰后是否更好？环境支持就截图，一图胜千 token。

   **390 微尺度**额外查五项：数字与地名/标签不碰撞；端点标签不越出画布；行末不出现
   孤立单字；按钮/链接不小于 44×44；最后一行不是「被压扁的桌面版」。这五项是
   绿页最常翻车的地方，比配色更影响「专业感」。

## 四个审美杠杆

多数人只调颜色，真正拉开差距的是这四个：

1. **尺度对比**：一个巨大元素 + 一群小元素。标题 120px 与标签 10px 同屏，比 32/24/18 的
   均匀字阶更有主张。巨大元素占 1 个，不要每个 section 都巨大。
2. **密度对比**：极疏与极密相邻。整屏留白后接一张 12 列数据表；一屏一图后接三行小字。
   均匀密度是模板的第一特征。
3. **表面**：纸、金属、玻璃、噪点、印刷网点、屏幕扫描线。表面要**一个**，不要五个。
   表面靠 CSS 实现（渐变、混合模式、SVG 噪声、repeating-linear-gradient），不贴图。
4. **边缘/收口**：光学对齐、1px 线的颜色、圆角与字号的比值、最后一个 section 的结束方式。
   边缘是专业与业余的分水岭。

## 材质取色（反默认）

先写材料，再取色。至少给每个色一个**材料理由**：

| 材料 | 可能的底色 | 不要默认成 |
|---|---|---|
| 回收毛毡 | 灰绿 `#6F7466`、暖灰 `#8C8578` | 奶油 `#F4F1EA` |
| 氧化铜/耐候钢 | 锈红 `#A63C25`、深褐 `#5A3326` | 陶土 `#D97757` |
| 哑光铝 | 冷灰 `#B8BDC2`、近黑 `#15171A` | 米白 `#FAF7F0` |
| 印刷纸/riso | 纸白 `#F1EEE4`、油墨 `#111110` | 奶油 + 衬线 + 陶土三件套 |
| 夜/海水 | 深海军蓝 `#07172A`、冷青 `#0A5F80` | 纯黑 + 荧光绿 |

如果最终仍选了「奶油 + 衬线 + 陶土」，必须能回答：这个题材的材料真的是纸/暖光/印刷吗？
答不出，就换底色或换强调色，不要换说法。

## 排版人格

- 一个或两个字体族；两个时必须**角色明显不同**（例如高对比衬线标题 + 几何无衬线正文）。
- 标题不是「更大的正文」：字重、字距、行高、宽度轴（若有）要一起变。
- 正文行宽 45–75 字符；衬线可略长，行高略高。
- 字阶用比值，不用手挑：1.2 / 1.25 / 1.333 / 1.5。相邻档 ≥1.2。
- 中文排版：标点挤压、避头尾、字重降一档、行高 1.7–1.9；不要用英文的负字距套中文。

**字体试衣**：标题至少试三种处理（同一字体不同字重/宽度；衬线 vs 无衬线；
正体 vs 斜体/描边），选那个「换一个品牌名就不成立」的。不要第一版就定。
把三种处理的截图或 ASCII 对比写进设计计划，说明为什么留这一个。

**避免**三种最常见的生成式排版处理：

- 标题里单独一个词用斜体/加粗/异色强调；
- 标签全大写 + 夸张字距（除非题材真的是工程标签）；
- 内容上方加不必要的 eyebrow 小标签。

## 构图

- **一个主导量**：页面第一眼必须有一个明确的最大块（图、字、色块、留白）。没有主导量 = 栅格。
- **非对称**：2 列不要 1:1，试 1.4:1 或 1:1.6；3 列不要等宽，试 2:1:1。
- **负空间是内容**：留白要有形状（L 形、带状、单侧大边），不是均匀 padding。
- **破一次格**：全页只允许一个元素越出栅格/压住边界/穿过两栏。破格是重音，多了是噪音。
- **边缘对齐**：至少两条看不见的线贯穿全页（左基线、右基线、或一条水平线）。

## 克制

- **把大胆花在一个地方**。一个元素成为记得住的东西，周围安静、有纪律。
- 砍掉一切不服务于简报的装饰。Chanel：出门前照镜子，摘掉一件配饰。
- 一个页面最多：1 个主结构、1 个注意瞬间、1 个破格、1 个表面、1 个强调色。
- 如果两个元素都在抢注意力，弱化其中一个，而不是加强另一个。

## 八个风格锚点（校准，不是菜单）

当简报明确说「瑞士」「粗野」「编辑感」「奢华」时，用这些锚点把词落到 token。
它们是**起点**，不是模板。选一个之后必须回答：这个项目为什么是这个风格？答不出就是选错了。

| 风格 | 色 | 字 | 布局 | 深度 |
|---|---|---|---|---|
| 瑞士 / 国际主义 | 白 + 黑 + 一个原色 | 无衬线，严格字阶，左对齐 | 强网格，非对称，大留白 | 无阴影，纯平面 |
| 粗野主义 | 高饱和撞色或纯黑白 | 系统字体/超粗，故意不精致 | 破格，大字号，边框可见 | 硬边阴影，无圆角 |
| 编辑型 | 米白/象牙 + 深墨 + 一个暖色 | 高对比衬线标题 + 无衬线正文 | 多栏，栏宽不等，首字下沉 | 无阴影，细线分隔 |
| 技术产品（Linear 型） | 近黑 + 单色强调 + 灰阶 | 几何无衬线，负字距 | 居中英雄 + 密集特性网格 | 极轻边框，表面亮度差 |
| 有机 / 自然 | 土色系，低饱和，暖 | 人文无衬线或柔和衬线 | 圆角，流动间距 | 柔和长阴影 |
| 复古未来 | 深底 + 荧光强调（青/洋红） | 等宽或科技感 | 网格叠加，数据装饰 | 发光，扫描线 |
| 奢华 | 黑/深绿/酒红 + 金 | 高对比衬线，大字距 | 极简，大留白，居中 | 极浅阴影，材质感 |
| 极简 | 单色 + 一个灰阶 | 单一无衬线，字重对比 | 极端留白，单列 | 无阴影，无边框 |

## 反默认指纹（命中即改）

以下是当前生成式 UI 的高频默认，不是「禁用」，而是**未经思考就出现**时必须改：

1. 暖奶油底（近 `#F4F1EA`）+ 高对比衬线标题 + 陶土/砖红强调（近 `#D97757`）。
2. 近黑底 + 单一荧光绿或朱红强调。
3. 报纸式大报排版：发丝线、零圆角、密集多栏。
4. SaaS 卡片套件：所有内容切成同款圆角卡片、同一个圆角、同一个软灰阴影、渐变洗底当装饰。
5. 模板 chrome：每个标题上方的全大写 eyebrow、用中点连接的 meta 串（A · B · C）、
   `WORD — fragment` 标签、用 `#0B0B0B` 冒充黑、小数据用等宽、所有链接末尾加 `→`。
6. 每个 section 都是 `fade-in-up`；每张卡片 hover 都抬升；logo 墙 40s 跑马灯。
7. 紫色 SaaS 渐变铺满全屏；玻璃拟态卡片当默认表面。
8. 居中英雄 + 大数字 + 三列 feature + 渐变 CTA 的固定五段式。

这些在**某些简报里完全合理**，但它们是默认值而不是选择。简报明确要，就照做；
简报没规定，就不要把自由花在这些默认上。

## 审美 rubric（0–5，写入审计）

| # | 维度 | 5 | 3 | 1 |
|---|---|---|---|---|
| 1 | 题材扎根 | 选择只能属于这个题材 | 行业通用但不出错 | 换个品牌名也成立 |
| 2 | 物理关系 | 布局与动效是同一关系的投影 | 有隐喻但未贯穿 | 只有栅格 |
| 3 | 排版人格 | 字形/字阶/字距形成可辨认的声音 | 干净但无性格 | 默认字族 + 均匀字阶 |
| 4 | 构图张力 | 有主导量、非对称、负空间有形状 | 整齐但平 | 居中/等宽卡片堆叠 |
| 5 | 克制 | 一个大胆点，其余安静 | 2–3 个争抢 | 每屏都在表演 |
| 6 | 完成度 | 边缘、光学对齐、终态都收口 | 首屏精致，尾部草率 | 明显未完成 |
| 7 | 动效编排 | 一个注意瞬间 + 因果几何 + 参数在簇内 | 有动效但各做各的 | 每区块 fade-in / 无 reduced-motion |

**通过线**：平均 ≥4.0，无单项 ≤2。这是「工作室可交付」的门槛，不是「能用」的门槛。
低于门槛时，先改 `01` 的六步与 `16-antipatterns`，不要改评分口径。

## 品牌语料怎么用

`assets/brands.json` 有 84 份 `DESIGN` 文档，每份是一个品牌的设计语言分析（MIT）。
用法是**读关系，不抄值**：

```bash
python3 -I scripts/query_corpus.py --brands
python3 -I scripts/query_corpus.py --brand linear.app --section colors
python3 -I scripts/query_corpus.py --brand apple --section typography
```

1. 选 3 个与题材气质相邻、但彼此不同的品牌。
2. 每个品牌只记三件事：**色彩关系**（谁是底、谁是面、谁只出现一次）、
   **字体角色**（标题/正文/数据各自承担什么）、**一个签名动作**（圆角、分隔线、留白比例、材质）。
3. 把三份记法写成一段「语言假设」，再决定自己的 token。
4. 不复制布局、文案、图形资产；不在交付物里保留品牌名，除非是明确的参考说明。

## 原型语料怎么用

`assets/patterns/` 有 14 张原型卡，来自 550 目录 → 412 抽取 → 379 可聚类站点。
每张卡给的是**区间**（字阶比值、字号档位、色度、明度跨度、间距基数、section 顺序），不是答案。

1. 用 `query_corpus.py` 找 1–2 张与简报相邻的原型，记下 ID。
2. 取 3–5 个区间作为约束，**不要抄中位数**。中位数会得到一张「像这个原型、但不属于你」的页面。
3. 如果都不匹配，明确说「无匹配原型，走自由方向」，并写出自己的 token 系统。
4. 原型不替代题材考古；它只防止你漂回默认。

## 两遍法（强制）

### 第一遍：设计计划（写代码前）

```text
SUBJECT:   是什么、给谁、主要任务（3 句以内）
MATERIALS: 3 个具体名词 / 2 种材料 / 1 个动词
PHYSICAL:  一个物理关系 + 为什么它解释内容
COLOR:     4–6 个命名 hex（底/面/墨/弱/强调/危险），写关系不写情绪
TYPE:      1–2 个字体族 + 角色 + 字阶比值 + 标题处理
LAYOUT:    一句话概念 + ASCII 线框 + 对齐方式 + 一个破格点
MOTION:    一个注意瞬间 + 它证明的物理行为 + 时长/缓动
FORBIDDEN: 本页禁止的 3 个默认（从第 8 节选）
```

这段不是形式主义。它让评审者能看出分级**确实做过**，而不是假定做过。
交付文件首行写 `DESIGN BRIEF` 注释，或单独的 `DESIGN` 文档。

### 第二遍：对照简报复查

检查计划里有没有任何一部分，是你对**任何类似页面**都会产出的默认值。
方法：想象一个相似但不同的需求（把建筑事务所换成瑜伽工作室），看会不会得到相似的计划。
如果有，改那个轴，说明改了什么、为什么。**确认相对独特性之后**才开始写代码。

## 自评十问

1. 第一眼看到的是什么？它是不是这个题材里最有特征的东西？
2. 第二眼在哪停？有没有第二个层级？
3. 摘掉一个装饰，页面是否更好？
4. 标题的字，是「更大的正文」还是「另一种声音」？
5. 颜色是否只在承担功能的地方出现？
6. 边缘（1px 线、圆角、间距、最后一行）有没有毛？
