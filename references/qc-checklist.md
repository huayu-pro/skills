# 交付质检

## 1. 出图后必跑

```bash
python3 scripts/lint_svg.py <文件或目录>          # 静态检查
python3 scripts/render_svg.py <文件或目录> --scale 2   # 出 PNG
python3 scripts/render_svg.py <目录> --sheet /tmp/sheet.png  # 批量拼版
```

判读：

| 结果 | 含义 | 动作 |
|---|---|---|
| 无输出 / PASS | 未发现结构性问题 | 仍要看 PNG，静态检查不替代目检 |
| WARN | 大概率缺陷 | 逐条看图确认；`[同层]`/`[等距]`/`[穿框]`/`[出框]`/`[行距]`/`[越界]` 六类应修，`[互压]`/`[贴边]`/`[重叠]` 目检裁定（template-catalog 注明「原图设计」的既有 WARN 豁免，不为它们返工） |
| FAIL | 结构性错误 | 必须修，不允许交付 |

WARN 是估算，不是判决。用目检结论覆盖它；反过来，目检发现了 lint 没报的问题，以目检为准。

## 2. 三项目检（每张必看）

看渲染出的 PNG，只看三件事：

1. **字号与框体协调**：正文四周留白均匀，标题不挤在框顶，注释不"漂"在空白里。
2. **元素位置**：同层等高、等距；引线对齐框边；整图不偏左/偏上。
3. **文字与边框关系**：不压线、不出框、不断字；行距不挤。

发现问题就回 SKILL.md 第 5 步改，改完重渲染。**最多 3 轮**；第 3 轮还不过，说明结构选型错了，回到第 2 步换模板。

## 3. 交付前清单

- [ ] 原图的每个标签都在图上，术语未被改写、未合并
- [ ] 结构方向与原图一致（层级自上而下、流程自左向右）
- [ ] 结构族判定有依据，没有硬套模板
- [ ] 画布四边留白 ≥40px，图题不在图内
- [ ] 新增/改动的坐标落在 8px 网格（`--grid` 只统计图形框，偏差数不作为硬指标）
- [ ] 同层模块等高、间距一致
- [ ] 文字不超框宽 90%，行距 ≥1.5×字号
- [ ] 分组框与成员框间距 ≥12px
- [ ] 箭头方向/线型语义正确（实线=直接，虚线=弱/反馈，双向=互动）
- [ ] 没有箭头穿框、没有零长度箭头
- [ ] marker 已定义且颜色与线一致
- [ ] font-family 已声明（根节点最优，lint 认文档任意处），中文渲染正常
- [ ] `lint_svg.py` 无 FAIL
- [ ] PNG 三项目检通过
- [ ] 文件名语义化，`.svg` 与 `.png` 同名

## 4. 缺陷对照表

| 症状 | 常见根因 | 首选修法 |
|---|---|---|
| 文字压框线 | 框高不足或字号偏大 | 框高 +8 或字号 −1；两行改单行 |
| 文字出框 | 未估宽 | 按 0.9 阈值加 `<tspan>` 换行 |
| 断字（半个字被裁） | 框宽小于单字宽 ×2 | 加宽框或缩字号，不允许裁切 |
| 行距挤 | tspan 间距 <1.4×字号 | 调到 1.5–1.9×（13px 字用 20–24px） |
| 同层高低不一 | 逐框手填 y | 统一顶边（新布局用 `带.y + 56`；套模板以实测为准） |
| 间距忽大忽小 | 局部挪框 | 整行重算等分 |
| 箭头穿框 | 直连两端未绕行 | 改正交折线，从中线拐弯 |
| 箭头不显示 | 零长度或 marker 未定义 | 端点留 ≥2px；marker 写进 `<defs>` |
| 分组框贴着成员 | 带内边距不足 | 内缩 ≥12（lint：<8 判红） |
| 重心偏一侧 | 内容区未居中 | 取包围盒后整体平移配平 |
| 整图偏小 | 画布留白过多 | 按包围盒裁画布或放大内容 |
| 中文变方框 | 缺字体或未声明 font-family | 根节点声明；装 Noto CJK |
| 改文字后末行残留半句 | 新文本行数少于旧 tspan 数 | 替换时同步删掉多余 `<tspan>` |
| 颜色过花 | 主色 >4 种 | 收敛到语义色板，同层同色 |
| 图内出现"图 1" | 把图题画进去了 | 删掉，图题交给排版 |

## 5. 批量抽检

批量输入的最小约定：一份清单（CSV 或表格）——`编号,结构族,原图路径,图题`；子代理按行领任务，产出 `编号_图题.svg/png` 到指定目录；返工只重跑清单中标记的行，不整批重排。

- 每批 100% 过 `lint_svg.py` 与 `render_svg.py`（脚本成本低，必须全量）。
- 主线程按 **20%** 抽检目检；抽检发现结构性问题，该批次改为 100% 目检。
- 子代理各自自检三项，交回时附 `lint` 退出码；退出码 1 的直接打回。
- 拼版总览（`--sheet`）用于快速扫"整体节奏"：层高是否一致、留白是否失衡、有没有明显空图。

## 6. 验收话术

合格的一句话标准：**把图给没读过论文的人看，他能说出"这是什么结构、从哪到哪、哪块是重点"。** 说不出来，说明结构没画清，不是配色问题。
