# 六道关卡

六个判断决定一份工作能否离开当前阶段。两个 **critical**：失败即停止交付。四个 **major**：失败必须修复或明确接受。

它们存在，因为"看着不错"不是标准。每道关卡点名的是没人检查时实际会出错的那个东西。

每个阶段边界读本文件。关卡不是最后跑一遍的清单：*Coverage* 与 *Citation* 在卡返回时查，*Angle* 与 *Calibration* 在结论写就时查，*Taxonomy* 与 *Weaving* 在初稿成形时查。

| 关卡 | 等级 | 问谁 | 拦什么 |
|---|---|---|---|
| **Angle**（判断） | critical | 结论 | 该下判断的地方交了来源综述 |
| **Coverage**（覆盖） | major | 计划与卡 | 建立在检索遗漏上的自信答案 |
| **Citation**（引文） | critical | findings 与参考文献 | 不存在的著作，或没说过这话的著作 |
| **Taxonomy**（分类） | major | 报告结构 | 章节重叠或漏掉真实区域 |
| **Calibration**（校准） | major | 每条主张的措辞 | 断言强于证据 |
| **Weaving**（织入） | major | 报告行文 | 一段一来源的目录 |

---

## Angle（critical）

结论必须承载**一句核心判断**，多于对来源的复述，且只有这项研究能得出它。

测试：删掉那句判断。若文本读起来仍像一份（哪怕无神的）完整综述，那就没有判断——只有覆盖。"文献呈现了多种观点"这种结论什么也没回答。

这是仔细的工作最常失守的关卡。覆盖全、引用足、行文好的结论若拒绝判断，就输在了唯一要求你思考的那道关卡上。

critical 意味着**失败即停止交付**：`check.py` 对两种机器可见的形状报 **P0**——结论以
"本文综述……""本报告梳理……"这类宣告综述的句式开头，或正文除标题外没有一句散文。
它只在结论写就时（阶段 3）就跑，不等到 `closed`：等到最后才查，等于允许一份综述形态的
结论在 synthesizing / reviewing 之间一路无人问津。

## Coverage（major）

计划覆盖表的每一行，要么有卡服务，要么标为声明缺口。

- **没人服务的行是缺口，不是疏忽。**没研究就在表里写明。
- **缺口不自动是失败**——带理由的缺口（"经约定不在范围""材料不可及"）是发现。没人注意到的缺口才是缺陷。
- **拿空格对照问题自己的措辞查。**问题点名了行为者、时段或地点，就该有卡碰它，或表里写明为何不。
- **关卡针对计划自己的主张**，不是绝对完备：它问设计是否做到了它声称要做的。

`check.py` **逐行解析覆盖表**，不只查"## 覆盖"标题在场：卡列为空且缺口列也没写理由的行
会被点名报 P1。标题在场说明不了任何事——空格就是这门禁的全部意义。

不要事后加卡填格子来过这关。为关格子派的卡产出一个段落；格子是设计，设计错了。

## Citation（critical）

每部被引著作存在，且说了被引的那句话。

失效模式，按损害升序：

1. **著作存在，页码错。**好修，发表出去难堪。
2. **著作存在，主张不在其中。**引文从别的论文继承来，或从标题想当然。这是最常见的严重错误。
3. **著作存在但不是所描述的那部**——不同版本、不同作者、译本当原著。
4. **著作不存在。**用像样的部件拼出的标题。先查*存在性*，再查内容。

两个信号值得起疑：

- **与检索词几乎完美匹配的标题。**真标题通常有点偏。过分贴切是常见的编造签名——核标识符，不要核措辞。
- **被引频次远超其产出的作者。**核具体那部。

对每条引文使用下面的引文五态。查不了的引文，不能当查过的呈现。

## Taxonomy（major）

报告的章节对研究产出的材料**互斥且合起来穷尽**。

- 章节标题命名**主题**，不命名来源或卡（"赔偿政治"，不是"卡 3"）。
- **真实的空格是发现。**某格没有材料，是关于该领域的信息，进正文。
- **跨格的著作被讨论，不被隐藏。**一部横跨两格的著作是分类尚不对、或两格实为一格的证据。
- **分类服务论证**，不服务参考文献：按材料显示什么组织，不按哪张卡找到它组织。

`check.py` 读终稿正文（无终稿时读初稿），对两种机器可见的形状报 **P1 并点名是哪几节**：

1. **章节按来源、卡或轮次命名**——标题形如 `Card 1`、`Source 2`、`卡 3`、`第 2 轮`。材料
   被归档，而不是被切分。参考文献与附录不算：它们是 `07-report.md` 要求的学术装置，
   不是论证章节。
2. **两节标题大部分词重合**（"赔偿政治的起源"与"赔偿政治的后果"）。重叠的标题意味着
   要么它们本是一节，要么分类还没按材料显示的东西切。判据按拉丁词与中文二字组比对，
   两节共享 ≥60% 的可用词即报。

它查不到"是否漏掉一块真实区域"——那是判断，机器只能看见你已经写下的标题。

## Calibration（major)

**断言强度绝不超过证据强度。**这是把学术报告与自信报告分开的关卡。

| 证据 | 至多主张 | 动词 |
|---|---|---|
| 多项独立研究、元分析或大规模验证 | **强** | 证实、确立、确认 |
| 两三项研究，或一项条件有限的稳健研究 | **中** | 提示、表明、指向 |
| 一两项研究，或仅有机制推理 | **弱** | 可能、或许、似乎 |
| 什么都没找到 | **按开放陈述** | "未检索到研究本方向……" |

两个方向相反的失败：

- **过度断言。**"证明了"、无限定的"最优"、未验证的"首次/唯一"。最高级只对点名的数据集与指标为真——写明哪个。
- **不足断言。**堆叠的对冲（"或许可以认为……"）埋没了证据支撑的发现。三项研究一致，就说它们一致。

major 意味着失败必须修复或明确接受，所以 `check.py` 对**过度断言**报 **P1**（门禁因此
真的会 FAIL，而不只是留一条 note）：出现 `proves / 证实了 / 证明了` 一类动词，或出现
`first study / the best / 首次 / 最优` 一类无限定最高级。按上表的动词降级即可通过。
**不足断言**（≥4 处堆叠对冲）仍只报 P2——它要协调人判断，机器只能提示。

另：**关联与因果分开。**没有因果推断证据就写"与……相关"；这不是文体偏好。

## Weaving（major）

行文必须**在段落内部比较来源**，而不是一段一个来源。

- 总结一部著作就收尾的段落是目录条目。它属于参考文献，不属于论证。
- **矛盾按条件分析，绝不平均**：在哪个范围、时段、方法、定义下各自成立？"证据不一"是没做这份工作的说法。
- **比较表配得上位置**才算数：展示要紧差异的比较表；列列完全相同的表是装饰。

这道关卡把研究文章与带注释的参考文献目录分开，也是报告从各节点段落拼装时最容易丢的那道。

`check.py` 读终稿正文（无终稿时读初稿），数**只引一份材料、且不含对比词**（however、
相比之下、然而、不同于……）的正文段落；当这类段落 ≥3 且占正文段落一半以上时报 **P1**
，并附其中一段的开头。留了个口子是因为：独份档案、方法说明这类段落本来就是单来源，
只有当"一段一来源"成为主导形态时，文章才是一份带注释的参考文献目录。

## 引文五态

`## Sources` 清单的每条、以及每条带定位符的 finding，五态居一。区分之所以要紧，是因为套错状态会用错补救。

| 状态 | 含义 | 怎么办 |
|---|---|---|
| `verified` | 标识符可解析、元数据吻合；引文就在所引处 | 不用动 |
| `partial` | 某项检查没过，或来源只支撑主张的一部分 | 把主张收窄到有支撑的部分，或写明哪部分无支撑 |
| `unverified` | 没人查过 | 查它，或删它；绝不当已查呈现 |
| `unreachable` | 抓取失败——来源很可能真实 | 标出来留给够得着的读者；**unreachable 不等于编造** |
| `invalid` | 注册机构拒绝标识符，或著作可证不存在 | **移除**；唯一恒为错误的状态 |

后两态的区分是整套设计的关键。把网络故障当编造，冤枉正确的工作；把被拒的标识符当临时故障，放走本流程唯一无法恢复的错误。

finding 里：

```json
{
  "text": "该敕令发布于 10 月 25 日。",
  "claim_type": "fact",
  "source_file": "sources/kampo-1918-1025.txt",
  "page": 3,
  "quote": "流行性感冒ニ関スル件",
  "citation_state": "verified",
  "single_source": true
}
```

`## Sources` 清单里，状态放在定位符后：

```markdown
## 来源（Sources）
- `sources/kampo-1918-1025.txt` — verified
- `sources/ji-1919-p87.txt` — partial：该页只支撑主张后半
- https://example.org/record/12345（抓取于 2026-10-20）— unreachable
```

`check.py` 把 `invalid` 当阻断、`unverified` 与 `unreachable` 当严重、未标注当未检查。

## 双源规则

**承重主张**——结论没它就塌的那条——需要**两个独立来源**，或显式 `single_source: true`。

- **独立**指来源彼此不派生。引同一条通稿的三篇文章、用同一数据集的三项研究，是一个来源。
- **单一来源是允许的。**档案、独份文献、一手证词常常只有一份。不允许的是把单一来源的主张拿出被佐证过的口吻——所以要有这个标记。
- **标记不是认罪**，它是给读者与审查员的信息——审查员接着可以问：第二来源存在吗。

## 关卡失败后怎么办

失败的关卡要**定向修复**，不是重启：

| 失败关卡 | 修复 |
|---|---|
| Angle | 重写开头的判断。不要重新研究——材料在那儿，缺的是主张 |
| Coverage | 后续轮用一张卡填格子，或在缺口列写明理由（只留空的格子不算声明） |
| Citation | 复查那条具体引文；把主张收窄到来源支撑的范围，或换来源 |
| Taxonomy | 重新切分章节。不是在现有标题间搬段落；按来源命名的标题要改成按主题命名 |
| Calibration | 按证据表重写那句话的动词；无限定最高级要么点名数据集与指标，要么删 |
| Weaving | 围绕分歧合并孤立段落，并点名条件 |

同一处失败两次的关卡，通常说明底层设计错了，不是措辞错了。带去见用户，不要第三次抛光。

## 关卡视图怎么读

`python3 "$SKILL_DIR/scripts/check.py" <project> --gates` 把同一批发现按关卡分组：

```text
ANGLE        (critical)  clear
COVERAGE     (major   )  FAIL
    P1  node n_a1b2  …coverage row(s) have neither a card nor a declared gap…
CITATION     (critical)  clear
TAXONOMY     (major   )  clear
CALIBRATION  (major   )  clear
WEAVING      (major   )  clear

verdict: FIX FIRST — 1 gate(s) at P1 (COVERAGE)
```

- 任一关卡（或 `UNGATED` 桶）有 P0 → `BLOCKED`，**exit 2**；有 P1 → `FIX FIRST`，exit 1。
  `UNGATED` 是不属于单一关卡的发现（例如缺 `review_rounds`）——它同样计入判定，不要
  因为它没挂在六个名字下就当它不存在。
- `--gates --json` 给出同样的分组与 `exit`，供自动化读；两者并用不会丢数据。
