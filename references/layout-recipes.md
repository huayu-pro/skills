# 布局配方

目标：任何一张图都能用公式算完坐标，不靠目测。记号统一：`M` 边距、`G` 间距、`W/H` 画布、`n` 元素数。

## 0. 通用常量

```
边距 M = 40（有引线标签的一侧按标签宽 + 24 放宽）
网格 g = 8        所有结果向 8 取整
同层横向间距 Gx = 24   （模板实际常用 40–80，等分算出多少用多少）
同层纵向间距 Gy = 20
层间间距   Gl = 40   （套模板时以模板实测为准）
模块高     h  = 72   （单行正文）/ 88–110（两行）
```

## 1. 等分（最高频）

n 个等宽模块铺满内容区：

```
内容区宽 CW = W - 2M
模块宽   w  = (CW - Gx × (n-1)) / n
第 i 个   x_i = M + i × (w + Gx)
```

算例：`W=1200, M=120, n=3, Gx=80` → `CW=960`, `w=(960-160)/3=266.7` → 取 264（8 的倍数），重新回填：`3×264+2×80=952`，剩余 8px 均分到两侧边距（`x_1=124`）。
**规则**：先取整再加回边距，不要让最后一框贴边。

纵向等分同理：`h = (CH - Gy×(n-1))/n`。

## 2. 层级/分层（层带型，参考 TP01/TP11/TP25）

```
层带高 hb = 160
层带 y_k = M + k × (hb + Gl)
模块高 h  = 72
模块顶 y  = y_k + 56        # 公式缺省；TP01 实测为 +16，套模板以实测为准
模块底 y  = y_k + 128       # 带内下留 32
层名基线  = y_k + 32，x = 带.x + 24
层间箭头  x = W/2，y1 = y_k + hb，y2 = y_k + hb + Gl
```

总高校验：`H = 2M + L×hb + (L-1)×Gl`。`L=3, M=48, Gl=48` → `96+480+96=672`，留白后取 800 是常见配置。

## 3. 流程/时序（流程链/泳道型）

单行流程：

```
w = (CW - Gx×(n-1))/n
框高 h = 200（流程链）或 80（泳道内）
首框 x = M
箭头  从 x_i+w 到 x_{i+1}，端点各留 0–4px
```

泳道：

```
泳道高 hl = 140
泳道 k 的 y = M + k × hl
泳道名框 x = M, w = 120
流程框 y = 泳道.y + (hl-80)/2 = 泳道.y + 30
跨道箭头：竖段 x 对齐目标框中线，先 V 后 H
```

## 4. 循环（环形/闭环型，参考 TP04/TP05）

n 个节点均匀分布在椭圆上：

```
θ_i = -90° + i × 360°/n
x_i = cx + a × cos(θ_i)      a = 横向半径（约 0.3×W）
y_i = cy + b × sin(θ_i)      b = 纵向半径（约 0.3×H）
节点尺寸按标签字数定（两行标签常用 280×88）：左上角 = (x_i - w/2, y_i - h/2)
```

弧线连接：相邻两节点用 `<path d="M 起点 A r,r 0 0 1 终点">`，半径取 `r = 1.4 × 弦长`，弧不要穿过中心圆。

环形分解（圆环型）：环外径按画布取（示例 `R=180`、内径 `r=120`），每段角度 `360/n`，路径用两段 `A` 闭合（外弧顺时针 + 内弧逆时针 + `Z`）。

## 5. 关系/机制（中介/调节型，参考 TP07/TP10/TP14/TP29）

```
主链 3 框：w = (CW - 2×Gx)/3，y 统一，垂直居中 y = H/2 - h/2
调节变量：与中介同 x，y = 主链.y - 88 - Gl
控制变量：与中介同 x，y = 主链.y + h + Gl
假设标签：箭头中点 (x1+x2)/2，基线 y_line - 4
调节箭头：默认从调节框底边竖直到中介框顶边；作用于某条路径时，
         终点 = 该路径箭头中点 (x1+x2)/2, 主链.y + h/2
无控制变量时：`H = 2M + 主链.h + 2×Gl + 调节框.h`（缺省值代入 ≈320；要更松的版式参考 TP29 实测——画布 520 高、M≈140），不要留空底
```

中心辐射（辐射型）：

```
节点按 360/n 均分，半径取 min(W,H)/2 - 180
连线：圆心 → 节点朝向圆心的一边中点
```

## 6. 矩阵（矩阵型）

```
行表头宽 cw = 120，列表头高 rh = 72
单元格  w = (CW - cw) / 列数，h = (CH - rh) / 行数
第 r 行第 c 列：x = M + cw + c × w，y = M + rh + r × h
```

格子数 ≤25；超出说明内容该做成表格而不是图。

## 7. 分解（树形型，参考 TP09/TP24）

树形：

```
根：(W/2 - w_root/2, M)
第 k 层 y = M + k × (72 + 88)
同层 n 个节点：w = (CW - Gx×(n-1))/n
连接：父底中点 → V 40px → 水平线 → 各子顶中点
```

鱼骨：

```
主脊 y = H/2，从 x=M 到 鱼头.x
主因 n 条，上下交替：斜骨起点 x_i = M + i × (脊长/n)
斜骨与主脊夹角 60°，骨长 160
```

漏斗：

```
每层宽 w_k = w_0 × (1 - 0.18k)
层高统一 96，层间留 16
层名放右侧：x = 漏斗右边 + 24，垂直居中
```

## 8. 文字宽度与换行

```
宽度估算：中文/全角 1.0×字号；大写字母 0.72×（W/M 0.9×）；小写与数字 0.55×；空格 0.3×；ASCII 标点 0.4×；中文字串里的歧义宽字符（·、希腊字母）按 1.0×
可用宽度：框宽 × 0.9（左右各留 5%）
逐字累加，超过可用宽度就换行；优先在「，、；：/空格/中文词组边界」断开
行数 l 时：框高 h ≥ l × 字号 × 1.8 + 32
```

算例：框宽 240，字号 13 → 可用 216 → 中文最多 16 字/行。若标题 20 字，必须两行。

## 9. 居中校验（写完必跑）

```
取所有非背景图元的包围盒 (xmin, ymin, xmax, ymax)
左留白 = xmin，右留白 = W - xmax
若 |左 - 右| > 24 或 |上 - 下| > 24，把整组图元平移 ±(差/2) 后再取整到 8
```

lint 的"重心偏移"靠目检，但这一步能先消掉大部分。

## 10. 增删元素时的重排纪律

- **只改数量不改顺序**：整行/整列重算，不单挪一个框。
- **插入新层/新阶段**：后续所有元素的 y 整体平移 `新增高 + Gl`，再重算画布高。
- **删掉一列**：剩余列重新等分，同时重算所有箭头端点与引线。
- **改了框宽**：同一行的兄弟框同步改宽；箭头起点跟着框边线走。
- 任何一次改动后跑 `lint_svg.py`，`[同层]`/`[等距]` 归零再继续。
