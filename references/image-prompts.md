# 配图与照片蒙太奇

构成主义的核心张力是**摄影 vs 几何**：一张纪实照片被硬边切开，压在色块和斜线里。
没有照片，做出来的只是"几何海报"——干净，但少了那层"证据感"。

默认仍然可以不用图（几何和字足够撑起多数学术/观点页）。但只要有巨物——人、产品、建筑、机器——就该走下面这条管线。

---

## 一、什么时候该用图

| 该用 | 不该用 |
|---|---|
| 封面需要一个"巨物"做尺度锚 | 每页都配图（图多了结构就散了） |
| 讲历史/人物/现场，需要证据感 | 抽象概念（换成几何更准） |
| 数据页需要一个实物参照 | 纯流程/结构说明（换成图示） |

一页最多一张图。一张图只承担一个意思。

---

## 一b、缺图怎么办（几何兜底）

多数学术/观点页不需要图。带可选图位的版式（槽位表里 form 为 `media` 且非必填，如封面的 `photo`、人物卡的 `portrait`、拼贴档案的 `bigImage`）在**不填图时，scaffold 会自动露出骨架里设计好的几何底块**——次墨窗、圆或楔形剪影。

- 底块是"有意的空窗"，不是"图没加载出来"；它是那一页的 L2 装饰层，删掉页面就塌一角。不要手删兜底块。
- 配图时图片整块盖在底块上，坐标不用动；`plan.mjs` 里 `media.photo`（或对应槽位名）留空即可。
- 全图版式（`L13`）的图是必填的——选它就要给图；不给图就换 `L21`（图文对切，图可缺省）。
- 兜底块的观感过一遍 `render` 联系表再交付（checklist 第 25 条）。

## 二、四步工序

以下命令都用 ImageMagick，可复现。以 `assets/img/industry.svg` 为例——那张网点化的工业剪影就是这么来的。

### 第 1 步 · 抠图

只有两种可靠情况：

```bash
# 纯色背景（白底产品图、扫描件）：按颜色去掉
convert src.jpg -fuzz 12% -transparent "#ffffff" cut.png

# 复杂背景：不要硬抠。用专门的分割工具出 alpha，再回到第 2 步。
```

抠完必须检查：**边缘有没有残留色环、主体内部有没有被误抠**。效果差就直接用原图裁切，别硬抠。

### 第 2 步 · 高反差单色

把照片压成"两色油墨"能印的样子：

```bash
convert cut.png -colorspace Gray -level 12%,88% -modulate 100,0 duo.png
```

- `-level 12%,88%`：把暗部压死、亮部提纯，中间调只剩一条窄带。这是"廉价印刷"的对比度。
- 想要纯剪影就再加 `-threshold 45%`。

### 第 3 步 · 网点化

这是最关键的一步——让照片看起来是**印上去的**，不是贴上去的。

```bash
# 3.1 做一张网点瓦片（10px 间距，半径 3）
convert -size 10x10 xc:black -fill white -draw "circle 5,5 5,8" dot.png

# 3.2 平铺到画布大小
convert -size 600x600 tile:dot.png dots.png

# 3.3 用剪影当遮罩求交（白点只留在剪影里）
convert dots.png mask.png -compose Multiply -composite alpha.png

# 3.4 生成"黑点 + 透明底"的成品
convert -size 600x600 xc:black alpha.png -alpha off -compose CopyOpacity -composite \
        -depth 8 -define png:color-type=6 industry.png
```

`mask.png` 是剪影：黑底、白色主体。可以直接用 `-draw` 画几何形状合成（见下），也可以用第 2 步的结果二值化。

**参数**：网点间距 8–12px（1280 宽画布），点半径 = 间距 × 0.28–0.32。点太密会糊成灰，太疏会散架。

### 第 4 步 · 硬边裁切

- 在 HTML 里用 `object-fit: cover` + 容器尺寸裁，**不要**用圆角、羽化、柔和遮罩。
- 需要斜切就用 `.wedge` 把图"压"进多边形里（图在下、楔形在上，或反之）。
- 图的边缘必须与版式的某条线对齐（栅格线、规线、画布边），不能浮在中间。

## 三、无版权素材怎么来

**不要用参考图里的照片**——那是别人的作品。三个来源：

1. **程序合成几何剪影**（推荐，零版权风险）。`industry.png` 就是这么做的：

```bash
convert -size 600x600 xc:black -fill white \
  -draw "rectangle 30,540 570,600" \
  -draw "rectangle 90,250 152,560" \
  -draw "rectangle 176,150 216,560" \
  -draw "rectangle 240,330 292,560" \
  -draw "rectangle 300,430 470,560" \
  -draw "rectangle 492,130 508,560" \
  -draw "rectangle 372,104 566,124" \
  mask.png
```

  画烟囱、塔吊、厂房、齿轮、船体都可以。几何剪影本身就符合构成主义的语法，比真实照片更"干净"。

2. **公共领域档案**：Wikimedia Commons、Library of Congress、Met Open Access。注意看授权条款。
3. **AI 生成**：见下一节提示词。生成图必须标注"示意图"，不得当作实拍。

## 四、AI 生图提示词

### 档案红黑（配 `theme-archive`）

```
1920 年代构成主义风格的档案海报。
主体：{{人物 / 机械 / 建筑}}，黑白高反差摄影质感，剪贴拼贴式处理，边缘硬朗，
压在 {{朱红 #D23B2C}} 的几何色块上。米白纸底 #F2EDE3，近黑 #141210。
一个巨大的正圆，被画布边缘裁掉三分之一。
一条粗斜线贯穿全幅，宽度约占画面 1/6。
轻微纸张颗粒与套色偏移。主体占画面 40-60%，被边缘裁切。
不要任何文字、字母、数字、水印。
```

### 靛蓝重墨（配 `theme-signal`）

```
构成主义双色印刷。
主体：{{人物侧影 / 产品 / 建筑轮廓}}，高反差，被压成 {{靛蓝 #3464C4}} 的单色块面。
暖白纸底 #F3F0E7。一个直径约画面高度 80% 的靛蓝正圆，位于右侧并被裁切。
一条宽 ≥48px 的斜带贯穿画面，角度 10-15°。
硬边直角切割，唯一允许的曲线是正圆。
不要细线，不要留白过半，不要任何文字。
```

### 报纸青墨（配 `theme-press`）

```

主体：{{人物 / 印刷机 / 街景}}，高反差双色调，压成 {{青墨 #227676}} 单色。
报纸米黄底 #F2EDDE，近黑 #191610。轻微纸张颗粒与网点。
一条粗斜带贯穿画面，标题位置留白。硬边直角。

```

### 彩色巨构（配 `theme-c1`…`c7`）

```
彩色新构成主义巨构海报。
主题：{{填主题}}
主体：{{人 / 产品 / 建筑 / 机械 / 天体}}，占画面 50-75%，被画布边缘大胆裁切。
配色：{{从 palettes.md 选一套，写四个 hex}}，面积严重不均。
一个巨大的正圆或圆弧压入画面，一条宽斜带贯穿全幅。
主体做几何化、符号化处理，轮廓强化，不追求繁琐细节。
复古印刷质感：细微网点、轻微套色偏移。
第一眼要有压迫感和空间统治力。不要任何文字。
```

**必须检查**：生成结果里出现文字就重做或裁掉——AI 图十有八九会加字。

## 五、往 PPTX 里放的时候

- 一律 `object-fit: cover`，**永远不要拉伸**。比例不对就裁。
- 透明 PNG 直接放，转换器会保留 alpha。
- 网点图本身是黑白透明 PNG，放在任何底色上都成立——这是它比"直接贴照片"好的地方。
- 同一张图不要在整份 deck 里出现两次（Logo、纹理除外）。

## 六、不要做的事

| 别做 | 为什么 |
|---|---|
| 生成"复古苏联宣传画"并写上俄文 | 那是另一件事，且容易做成政治符号的廉价挪用 |
| 用 AI 图充当数据或事实 | 会被当真。生成图必须标注"示意图" |
| 给图加圆角、投影、玻璃拟态 | 与硬边直角切割直接冲突 |
| 满页都是图 | 构成主义的主角是结构，不是图片 |
| 用参考图里的照片 | 版权问题 |
