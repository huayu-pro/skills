# 25 · Golden pages — 审美高度的三个基准

> 这三页不是模板，是**质量地板**。它们证明这个技能要求的审美高度是可达到的；
> 不是让你照着它们做，而是让你在自评时有一个可对照的实物。
> HTML 可直接打开；按 no-binary 约束，仓库不携带截图/PNG。

## 怎么用

1. 写代码前看一遍，记下**一个**你想达到的品质（不是抄布局）。
2. 写完后把 1280 截图与 golden 并排放，问：我的页面缺的是结构、字、色、还是收口？
3. 用 `01-aesthetic-direction.md` 的 7 维 rubric 打分；golden 页是 4.5–5 的参照。
4. 不要复制它们的文案、品牌名、具体配色；它们是不同题材的答案。

## 1. Aperture — 编辑型技术产品页

**文件**：`assets/golden/aperture.html`（22 KB，自包含）
**截图**：评审时渲染；不随包分发（no binaries）。

**题材**：一个「每个决策都需要证据」的分析产品。不是 SaaS 工具，是一份**立场文件**。

**物理关系**：网格纸 + 档案页。页面像一张被摊开的证据表：64px 方格底、左右 1px 装订线、
顶部状态条、分栏的「论点 / 证据 / 价格」。

**可指认的选择**：

| 维度 | 做法 | 为什么成立 |
|---|---|---|
| 色 | 纸白 `#F1EEE4` + 墨黑 `#111110` + 红 `#DF3F26` + 蓝 `#1E33C8` | 红只做状态/强调，蓝只做链接/次强调；两色各有职责，不是装饰 |
| 字 | Helvetica 无衬线正文 + Georgia 衬线标题 + IBM Plex Mono 标签 | 三种角色清楚：读、主张、标注 |
| 构图 | 1.06:0.94 非对称 hero；证据表跨两栏；价格三档不等宽 | 有主导量，不是等分卡片 |
| 表面 | 纸色 + 方格线 + 1px 装订线 | 一个表面，贯穿全页 |
| 动效 | 状态点 2.4s pulse（唯一常驻）+ IO reveal 450ms | 一个注意瞬间，其余只解释变化 |
| 收口 | 状态条、页脚、价格卡的边线全部对齐同一套基线 | 边缘没有毛 |

**可迁移**：
- 用「一种底色 + 两种有职责的强调色」替代五颜六色。
- 用等宽小字做标签/状态，但**不要全大写 eyebrow**；这里的状态条是真实状态，不是装饰。
- 非对称 hero 的比例（1.06:0.94）比 1:1 更有张力，但差距很小，适合「克制」的题材。

**不要照搬**：纸白+红蓝是这页的答案，不是所有技术产品的答案。换题材要重新做题材考古。

## 2. Atelier North — 建筑事务所的图纸页

**文件**：`assets/golden/atelier-north.html`（20 KB，自包含）
**截图**：评审时渲染；不随包分发（no binaries）。

**题材**：建筑、室内、物件的实践。页面不是「作品集网格」，是一张**图纸**。

**物理关系**：图纸 + 标题栏（title block）。顶部是项目/比例/日期/坐标的表格，
下面是剖面式的项目叙述；网格线是图纸的坐标纸，不是装饰纹理。

**可指认的选择**：

| 维度 | 做法 | 为什么成立 |
|---|---|---|
| 色 | 纸 `#F5F2EA` + 墨 `#16150F` + 氧化红 `#A63C25` + 灰 `#7A7468` | 氧化红只出现在标题的斜体词和 hover 线；像材料样本，不像 CTA |
| 字 | Iowan/Palatino 衬线标题（clamp 42–118px，行高 .86，字距 -.05em）+ Helvetica 正文 + 等宽标签 | 标题是「建筑的比例」，不是「更大的正文」 |
| 构图 | 1.55:0.6 非对称 hero；title block 五栏；项目段落左对齐、右侧留白 | 负空间有形状（右侧大边），不是均匀 padding |
| 表面 | 图纸网格 + 1px 线 + 无阴影 | 一个表面，零深度，靠线与比例 |
| 动效 | reduced-motion 直接终态；IO reveal；hover 只改下划线颜色 | 建筑题材不需要表演 |
| 收口 | 每个 title block 单元格的 1px 线连续；页脚结束在一条水平线上 | 图纸的纪律 |

**可迁移**：
- 用「标题栏/元数据表」替代 hero 的三行文案；它同时是导航、状态和气质。
- 衬线标题 + 无衬线正文 + 等宽标签的三层字角色，比「一个字体走天下」更有主张。
- 斜体只用一个词，且必须是题材里的词（不是「*创新*」）。

**不要照搬**：衬线 + 氧化红 + 图纸网格是建筑语的答案；换成美妆/金融会假。

## 3. Studio — 12 机制的动效实验室

**文件**：`assets/golden/studio.html`（115 KB，自包含，单脚本）
**截图**：评审时渲染；不随包分发（no binaries）。

**题材**：一个动效研究页，把 12 个机制放在同一页，共享 state 与主循环。
页头写「302 → 30 → 12 → this page」，它是整个逆向工作的索引。

**物理关系**：不是单一关系，而是**机制目录**：每个 section 是一个可操作的实验台
（滚动叙事、物体轨道、旋钮、声音、光标、扫描……），彼此用同一条编辑式网格串起来。

**可指认的选择**：

| 维度 | 做法 | 为什么成立 |
|---|---|---|
| 结构 | 12 个 section = 12 个机制，每个有标题、参数、可操作 demo | 结构即信息；不是「效果大杂烩」 |
| 色 | 近黑底 + 暖金强调 + 灰阶 | 让 12 个 demo 的图形成为主角，chrome 退后 |
| 字 | 几何无衬线 + 等宽参数标签 | 参数是内容，标签要有仪器感 |
| 动效 | 每个 demo 一个主机制；共享主循环；reduced-motion 全部终态 | 12 个机制不打架，因为每个 section 只做一件事 |
| 收口 | 每个 demo 有边界、暂停/恢复、参数读数 | 实验室的纪律，不是作品集 |

**可迁移**：
- 多个动效同页时，用**分区 + 共享时钟**，不要让它们互相抢滚动/指针。
- 每个 demo 暴露 1–2 个参数（速度、摩擦、半径），让读者能感到机制，而不是看魔法。
- 深色页面用暖金/单一强调，比荧光绿+紫更耐看。

**不要照搬**：这是「机制目录」的题材，不是普通产品页。普通页面不要放 12 个 demo。

## 三页的共同点

1. **一个物理关系**：证据表 / 图纸 / 实验室目录。不是「现代简洁」。
2. **一个表面**：纸、图纸、近黑。没有五种材质混用。
3. **三种字角色**：标题、正文、标签。不是一套字阶走天下。
4. **图表/示意图不独占首屏**：aperture 的证据表在右、标题在左；atelier 的剖面在第二屏；
   studio 的机制有文字与参数。图表是支撑，不是英雄。
4. **一个注意瞬间**：状态点、hover 线、或每个 demo 自己的主机制。
5. **边缘收口**：1px 线、基线、页脚结束方式都对齐。
6. **移动端是重新排**，不是缩小：aperture/atelier 的 375 渲染都保持同一套网格与字角色。

## 自评对照表

| 问题 | 看哪一页 |
|---|---|
| 我的页面有没有主导量？ | aperture 的 hero / atelier 的标题 |
| 我的字有没有三种角色？ | atelier 的衬线/无衬线/等宽 |
| 我的颜色有没有职责？ | aperture 的红/蓝 |
| 我的表面是不是只有一个？ | 三页都有 |
| 我的动效是不是只有一个注意瞬间？ | aperture 的状态点 / studio 的分区 |
| 我的 375 是不是重新排？ | 三页的 mobile 渲染 |
| 我的边缘有没有毛？ | atelier 的 title block 线 |

## v5.0 · 按 profile 选对照页

| profile | 对照 | 看什么 |
|---|---|---|
| expressive/editorial | aperture / atelier-north | 结构、字角色、收口 |
| catalog | studio | 分区、共享时钟、暂停 |
| utility/product | ledger | 克制、状态、反馈、信息密度 |

三页纸感/图纸/近黑是具体题材的答案，不是通用品味。`ledger.html` 是安静的财务/设置页：
冷灰、无衬线、tabular numerals、1px 分隔、无纸感/无阴影；0 attention / 0 ambient，
动效只有 120–200ms 反馈。它证明「得体的安静」也能达到 4.5–5。
