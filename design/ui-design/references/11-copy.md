# 界面文案

> 教材未覆盖，本文件综合 Anthropic frontend-design 的写作原则与产品文案实践。

## 核心立场

文字是设计内容，不是装饰。它在界面里的唯一理由是**让人更容易理解和操作**。

所以写文案和调间距是一回事：都要问「这里需要什么」，而不是「能填什么」。

## §11.1 从用户视角命名

用用户理解的语言，不用系统实现的语言。

```
✗  Webhook 配置            ✓  通知设置
✗  数据实体管理            ✓  客户
✗  提交                    ✓  保存更改
✗  认证失败                ✓  密码不正确
```

判断方法：一个没用过这个产品的人，能不能猜出点下去会发生什么。

## §11.2 动词开头，说清结果

按钮文案回答「会发生什么」，不是「这是什么操作类别」。

```
✗  Submit / 确定 / OK
✓  Save changes / 保存更改
✓  Send invite / 发送邀请
✓  Delete 3 files / 删除 3 个文件
```

同一个动作在全流程用同一个词：按钮写「发布」，Toast 就写「已发布」，不要换成「提交成功」。

## §11.3 错误文案

三个要素，缺一不可：

1. **发生了什么**（具体）
2. **为什么**（如果知道）
3. **下一步做什么**（一个动作）

```
✗  出错了
✗  抱歉，出了点问题，请稍后重试
✓  无法保存：文件超过 10MB 上限。请压缩后重试。
✓  邀请发送失败：该邮箱已有待处理的邀请。可撤销旧邀请后重发。
```

规则：
- 不道歉（道歉不解决问题，还占用注意力）
- 不卖萌（"哎呀，出小差了" 在错误场景里让人恼火）
- 不模糊（"系统错误" 等于没说）
- 保留用户的输入（错误后不要清空表单）

## §11.4 空状态文案

> **扩展章节**：原书没有第 11 章。§11.x 编号是本 skill 自建的；
> 空状态的结构规则在原书 §8.4。

```
✗  暂无数据
✗  No results found.        ← 这是搜索无结果，不是首次使用
✓  还没有项目
✓  创建第一个项目，开始追踪你的部署
```

区分两种空：
- **首次使用**：解释这是什么 + 主行动
- **搜索无结果**：说明没找到 + 清除筛选的出口

RED 基线里的 P0 就是这个混淆：首次使用的页面写了搜索失败的文案。

## §11.5 大小写与标点

- 中文：正常标点，全角。
- 英文：句首大写（sentence case），不要 Title Case（除品牌名）。
- 按钮和标签不加句号。
- 不要用感叹号（除了真的值得庆祝的一次）。
- 不要用 emoji 做状态指示（屏幕阅读器会读出来，且跨平台渲染不一致）。

## §11.6 长度

- 按钮：1–3 个词。
- 标题：不超过两行。
- 说明文字：不超过两行，超过就考虑是否必要。
- 表单标签：1–2 个词。
- Toast：一句话，能一眼读完。

**删掉填充词**：「请」「请注意」「您需要」「在这里」「点击」通常都可以删。

## §11.7 术语一致性

同一个概念只有一个词。建一个词表：

| 概念 | 统一用 | 不要用 |
|---|---|---|
| 项目 | 项目 | 工程、空间、工作区 |
| 删除 | 删除 | 移除、清除、清空（除非语义确实不同） |
| 设置 | 设置 | 配置、偏好、选项 |

混用同义词会让用户以为是不同的东西。

## §11.8 数字与单位

- 数字用阿拉伯数字（"3 个文件" 不是 "三个文件"），除非是固定短语。
- 单位与数字之间加空格（`10 MB`、`200 ms`）。
- 大数字用分隔符（`1,234`）或缩写（`1.2k`），但表格内保持一致。
- 时间用相对还是绝对要看场景：日志用绝对（带时区），活动流用相对（"3 分钟前"）。

## §11.9 占位内容不是文案

`Lorem ipsum`、`标题在这里`、`示例文本` 会让整个设计看起来是假的。用**真实的、具体的**内容：

```
✗  Product name          ✓  Meridian
✗  Lorem ipsum dolor     ✓  每次部署都能看到完整的调用链
✗  User 1, User 2        ✓  陈静, 李维
```

虚构但要具体。具体的假内容能暴露真实内容才会有的问题（长名字、长标题、空值）。

## 快速自检

1. 每个按钮是否说清了点下去会发生什么？
2. 错误文案是否包含原因和下一步？
3. 首次使用和搜索无结果是否用了不同文案？
4. 同一概念是否只有一个词？
5. 有没有 Lorem ipsum 或「示例文本」？
6. 能不能删掉一半的字而意思不变？
