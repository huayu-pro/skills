# 图像与媒体

> 教材第 7 章。规则编号 `§7.x` 对应 *Refactoring UI* 原书章节。

## §7.1 图像是布局的一部分，不是填充物

一张图放进容器，要么它**决定**容器的比例，要么它**服从**容器。两者混用是混乱的根源。

| 模式 | 用法 | CSS |
|---|---|---|
| 图像定比例 | 摄影、插画主导的页面 | `aspect-ratio` 由图像本身决定，容器跟随 |
| 容器定比例 | 卡片缩略图、头像、封面 | `aspect-ratio: 16/9` + `object-fit: cover` |

**不要**用 `object-fit: fill`（会变形）。**不要**让图像用 `width: 100%; height: auto` 又在外层设固定高度（会产生空洞）。

## §7.2 图像需要裁切策略

`object-position` 是经常被忘掉的关键属性。默认 `center` 在人物照上会切掉头，在产品照上会切掉主角。

```css
.avatar    { object-position: center 30%; }   /* 人脸偏上 */
.hero-shot { object-position: center top; }   /* 界面截图保留顶部导航 */
```

## §7.3 文字叠在图像上

三层保障，缺一层就可能不可读：

1. **遮罩**——`linear-gradient(rgba(0,0,0,0) 40%, rgba(0,0,0,0.7))`
2. **模糊**——`backdrop-filter: blur(8px)` 局部使用
3. **文字阴影**——`text-shadow: 0 1px 3px rgba(0,0,0,0.4)`

**必须验证**：文字所在区域的最亮处与文字颜色的对比度。整图平均对比度没有意义——文字可能正好落在亮斑上。

做法：截图后取文字覆盖区域的像素，算最亮/最暗与文字色的对比。

## §7.4 图标

- **尺寸档位**：16 / 20 / 24 / 32。不要用 18、22。
- **笔画粗细**：同一组图标必须一致。混用 1.5px 和 2px 笔画看起来像两个图标库。
- **风格一致**：线性全线性，面性全面性，不要混。
- **对齐**：图标与文字基线对齐用 `align-items: center` 而不是 `vertical-align`。
- **颜色**：图标颜色跟随文字色（`currentColor`），不要单独硬编码。

**尺寸陷阱**：图标在按钮里不要手写 `w-4 h-4`，让按钮组件自己控制（见 `15-stack-shadcn.md` 的 `data-icon` 规则）。

## §7.5 截图与产品图

产品界面截图是最有效的信任建立物，但也是最容易搞砸的：

- **不要拉伸**：按原始宽高比。
- **加外框**：1px 边框 + 多层阴影 + 圆角，让截图看起来是「一个窗口」而不是「一张图」。
- **背景衬托**：截图放在比页面背景稍深的表面上，边界才清晰。
- **高 DPI**：至少 2x，否则在 Retina 上糊。

## §7.6 图像加载状态

图像是异步的，必须有三种状态的设计：

1. **占位**——固定 `aspect-ratio` 的骨架，避免布局跳动（CLS）。
2. **加载失败**——`onerror` 回退（头像用首字母 + 背景色）。
3. **空**——没有图像时的默认视觉（不是破图图标）。

## §7.7 背景图案与纹理

- 点阵 / 网格：`background-image: radial-gradient(...)` 或 SVG pattern，透明度 3–8%。
- 噪点：SVG `feTurbulence`，`opacity: 0.02–0.04`。
- 渐变网格：多个大半径 radial-gradient 叠加，色相接近。

**不要**用高对比的装饰图案压在文字后面。

## 快速自检

1. 每张图的裁切策略是否明确（比例 + `object-position`）？
2. 文字叠图是否做了遮罩，且验证了最亮区域的对比度？
3. 图标是否同一套、同笔画、同尺寸档位？
4. 图像是否有占位、失败、空三种状态？
5. 截图是否有外框和阴影？
