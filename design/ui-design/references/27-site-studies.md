# 27 · 站点研究（一份内容，六种设计语言）

> 这个受控实验已收进 `assets/site-studies.html`：**同一份内容**（Atlas Type 字体项目）
> 用六种完全不同的设计语言各做一页，再加一个索引；左侧选页。它不是六个模板，
> 而是让你看到「内容不变，语言怎么变」。
>
> 用法：先读 `07-index` 的总览，再挑 2 个与你题材最远/最近的语言对照。
> 不要六个都抄；抄一个语言的结构关系，不抄具体色值。

## 索引

- `07-index.html`：六种语言的样张索引，按语言列出关键差异。
- `index.html`：整个研究的入口，说明实验目的与用法。

## 怎么用

1. 先确定你的题材：技术、编辑、极简、夜航、工业、轻盈——选**一个**最接近的。
2. 打开对应页，记三件事：**底色与面的关系**、**字角色**、**结构装置**（线/编号/色块）。
3. 再打开一个最远的语言，问：如果把这个结构关系搬过来，会不会更有主张？
4. 只搬关系，不搬色值/文案/图形；六页共用一份内容，说明内容不是设计的来源。
5. 你的页面必须能回答：为什么是这个语言，而不是另外五个？

## 共同点

- 六页都只有**一个**表面（纸/夜/工业/天空），没有材质混用。
- 六页都只有**一个**强调色，且只出现在状态/链接/关键数字。
- 六页都用**线的纪律**（1px、对齐、连续）而不是阴影做层次。
- 六页的移动端都是重新排，不是缩小。
- 六页的动效都克制：IO reveal + hover 线，没有每屏表演。
