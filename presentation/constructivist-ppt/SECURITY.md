# 安全边界

这个 skill 是一个本地排版/编译工具，不上传代码、不联网、不执行远程脚本。

## 读取面

- `pack-html.mjs` 只接受 `.html` / `.htm` 输入。
- 它只内联图片、字体与样式表扩展名；其他扩展名、无扩展名文件一律拒绝。
- 路径必须经过 `realpathSync` 后仍位于 `--root` / 页面目录 / skill 目录围栏内。
- 路径中不允许出现隐藏段（以 `.` 开头的目录或文件名），因此不会去读凭据目录。
- SVG/CSS 文本额外扫密钥特征串；任何一条不过都不写盘。
- 错误信息只报告被拒绝的引用与原因，不打印文件内容。
- 转换/校验脚本只调用本地 Chromium、LibreOffice、ImageMagick、poppler；没有网络请求与 shell 拼接。

## 打包

交付 zip 不包含 `scripts/node_modules`、`evals/runs` 或 baseline 预览图；这些是本机依赖与临时产物。仓库/压缩包内不应出现密钥或凭据文件。

## 报告问题

如果发现读取面、围栏或打包策略有缺口，请附上复现命令与最小 fixture；不要在 issue 里贴真实凭据。
