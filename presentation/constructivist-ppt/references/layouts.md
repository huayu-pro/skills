# 版式：设计意图

**几何在骨架里，槽位在表里。** 每个版式的精确坐标以 `assets/layouts/L*.html` 为准，
槽位、必填项、字数上限、缩略图见 `layout-specs.md`。这一页只解释“为什么这样排”。

---

## 选版式

先定 `role`，再选支持这个角色的骨架。角色与候选版式的对照由 `layout-specs.md` 的“角色 → 版式”表维护。

不要按标题选版式——标题相似的页面可能承担完全不同的叙事任务。比如“一条线”可以是封面（L01）、宣言（L07）或对比（L09）。

---

## 逐个版式

| 版式 | 意图 | 关键约束 |
|---|---|---|
| **L01 巨构封面** | 一个巨物 + 一个巨大标题 + 一条主斜线；巨物被画布边缘裁掉一部分 | 标题与斜线咬合；巨物不完整才有压迫感 |
| **L02 档案封面** | 比 L01 克制；标题块 + 编号格 + 三行元数据 | 编号格用 `.counter`；适合内部汇报 |
| **L03 章节幕** | 只放章节号 + 章节名；墨底 + 出血巨圆 | 不放理由、不放摘要；标题两行最多 |
| **L04 1+3 方法页** | 首栏吃掉份额，其余三栏支撑；首栏 1.9fr | 只用 `.grid4--lead`；禁止等宽四栏 |
| **L05 巨号数据 / 时间轴** | 深色斜板托起巨号数字与标签 | 3–4 项；数字是主角，说明是配角 |
| **L06 左右硬切** | 一侧纸底、一侧墨底，切边是硬的 | 深色侧页脚要反白或缩到浅色区 |
| **L07 斜切宣言** | 楔形从一侧推进；文字在楔形左边之外 | 楔形左边缘是文字栏右界 |
| **L09 双栏对比** | 中间一条 2px 竖线，两侧各三条理由 | 不要给两侧加底色块，否则变成卡片 |
| **L10 引语** | 左侧竖条 + 大引语 + 署名 | 引号用真文本；引语最多两行元素 |
| **L11 条形图** | 只用条形和数字，不加坐标轴/网格线 | 条形长度按数据等比；数值标在末端 |
| **L12 人物 / 作品卡** | 卡片沿斜线依次下沉；首卡最大 | 不要做成等高等宽四栏；字母可以做肖像 |
| **L13 全图压字** | 满幅图/色块打底，标题压在实色带上 | 不做半透明蒙层；实色带或把蒙层烘焙进图片 |
| **L14 目录索引** | 行 + 2px 分隔线 + 编号/年代 | 行高统一；序号与年代两端对齐 |
| **L15 清单 / 表** | 去网格：只留横线，表头加粗 + 3px 顶线 | 数值列右对齐；不放竖线 |
| **L16 行动结尾** | 墨底 + 斜带 + 一句可执行的话 | 不要“谢谢聆听”；给下一步动作 |
| **L17 大圆聚焦** | 巨圆出血 + 斜带从圆后穿出；文字左侧压场 | 巨物要被裁掉一角才有力；`stat` 巨号数字压在圆心 |
| **L18 台阶进程** | 四级台阶从左到右爬升，右缘竖楔封边 | 台阶高度必须递增出面积差；文字坐在每级台阶上方 |
| **L19 拼贴档案** | 大格证据窗（可缺图）+ 右侧深格 + 底部注释格 | `bigImage` 缺省时露出几何底块，不是空白 |
| **L20 横向时间轴** | 水平脊线 + 节点交替上下 + 右缘竖楔 | 起点最重；节点文字不压脊线，楔形走廊不放文字 |
| **L21 图文对切** | 右半张整幅图区（可缺图），左半张主张 | `image` 缺省露出兜底构成；切边由斜带咬住 |

**L08 已并入 L05。** 三项时间轴用 L05，把 `items` 设为 3 项；scaffold 会删掉第 4 项块。

## 节奏

- 连续同 layout / family 不超过 2 页（`STRUCTURE` 会判）。
- 单个版式占比不超过 40%（页数 ≥8 时，`STRUCTURE` 会判）。
- 推荐：封面 → 背景/宣言 → 方法 → 数据 → 案例 → 对比/引语 → 结尾。
- 章节幕只在页数足够时用；少于 12 页时它会打断节奏。
- **镜像方向**：`axisDeg` 支持逐页覆盖（slide 级字段）。相邻两页把 `-11` 与 `+9` 之类的正负角交替，斜线方向翻转，同一骨架立刻有了第二种读法——这是零成本打破单调的第一手段，比换配色有效。
- **但有版式不能翻符号**：横置斜带贴着标题区的骨架（`L01 / L05 / L12 / L15`，契约里标 `axisDegSign: negative`）只对负角安全，翻正角斜带会压住文字，`plan.mjs` 会直接警告。这些版式要变化就调角度绝对值（如 `-11` → `-7`），或换竖置斜带的骨架。

## 可选图位（图可以不加，但设计里一定有它）

`L02 / L06 / L12 / L16 / L19 / L21` 带可选 media 槽位（`photo` / `portrait` / `bigImage` / `image`）。骨架在图位下层放了几何兜底（次墨窗 + 圆/楔剪影）：

- plan 里不填 `media.*` → scaffold 删掉 `<img>` 块，兜底构成露出，页面完整成立。
- 填了 → 图片整块盖住兜底，坐标不变。
- 每页仍然最多一张图；配图原则见 `image-prompts.md`。

---

## 全图与半透明

L03 / L13 旧版曾要求“半透明叠层”。**不要这样做**：PPTX 会把透明度拍平，预览与成品不一致。

- 需要压暗图片：用实色 `--fg` 带，或把蒙层烘焙进图片（ImageMagick）。
- 需要“透出一点”：用 `--alt` 的实色块，或降低面积，不要用 CSS `opacity`。
- 半透明元素会被 `OPACITY` 判，`validate` 会把文本透明报 error。

---

## 坐标与改版

- 骨架里的 `left/top/width/height` 是设计决定，不是随手值。改一页的坐标前，先问“这个版式的其他页面要不要一起改”。
- 要新增版式：先在 `layouts.json` 登记 id / roles / slots，在 `assets/layouts/` 下新增 `Lxx.html`，然后跑 `gen-layout-docs.mjs` 和 `selfcheck.mjs`。
- 只改文案时，不要动骨架；scaffold 的槽位预算会先拦住超字数。
