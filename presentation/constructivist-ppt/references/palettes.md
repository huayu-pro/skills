# 配色

**一套 deck 只用一套主题。** 中途换色等于暗示“翻到另一份材料了”。

**角色只有五个，但信息色只有四个**：纸 `--bg`、主墨 `--fg`、爆点 `--pop`、次墨 `--alt`；`--mute` 只给 标签档的页码/标签（见规则 9），**不计入四色、不能做副标**。没有“浅色底板”这个角色——多给一个角色，它一定会被拿去做卡片。

### A · 档案红黑

三套同语法、不同油墨：正红最锐，焦墨偏暖，锈橙偏沉。红系承载立场，黑提供结构，米白是主动的负空间。

**气质**：硬、旧、压得住　**适合**：文化、品牌、观点型分享、需要档案感的回顾

同一套语法换一种墨。不是极简双色：必须有粗斜带、实心墨块和压得住的面积。靛蓝偏科技，青墨偏报刊档案。

**气质**：冷、重、精确　**适合**：科技产品、数据汇报、工程/设计分享、报刊档案向内容

## 怎么选

| 内容 | 选 |
|---|---|
| 讲一个历史、一个品牌、一个观点 | A 档案红黑 |
| 讲一个产品、一组数据、一个系统 | B 靛蓝重墨 |
| 讲一个活动、一个创意、一次宣言 | C 彩色巨构（挑一套跟主题有情绪关联的） |

**不要**为了“看起来高级”选 C。撞色的前提是内容本身有冲突感或能量；平静的内容配撞色会显得吵。

子风格的同一版式对照图是生成物（发布包不含二进制）。要看图时跑：

```bash
node scripts/style-preview.mjs examples/demo-31.html --out examples/style-comparison
```

默认覆盖 themes.json 里的全部主题。先看图，再决定。

## 子风格的硬约束

### A 档案红黑

- 必须有 `.grain`；没有颗粒，纸底会像米色背景板。
- `--pop` 只给一个主张：编号、几何、单句强调，不做正文。
- 反白用 `var(--bg)`，不要写 `#FFFFFF`——后者不在主题里。

### B 靛蓝重墨

- **不是极简双色。** 早先那版用 1px 发丝线 + 60% 留白，做出来是瑞士国际主义，不是构成主义。
- 必须有一条 ≥10° 的粗斜带或斜切色块，宽度 ≥48px；线一律 2px 起。
- 面积按速查表的配方；禁止大面积留白。冷静来自**高纯度重墨 + 大面积单一色块**，不来自“空”。
- 如果做出来“很干净但没有压迫感”，就是又滑回瑞士风了，回去加色块面积。

### C 彩色巨构

- 仍然是**两墨一纸**，只是把固定的红黑换成撞色；不是多彩 UI。
- 必须有：一个 ≥40% 画布的巨物、一条 ≥10° 的斜切、颗粒层。
- 每次新建 deck 重新选一套，不要复用上一份的颜色。
- 撞色只换墨，不换语法：斜线、面积差、极端尺度、硬边直角一个都不能少。

## 用色检查

1. `--pop` 在整份 deck 里出现的位置 ≤ 每页 2 处。
2. 任何一页，最深与最浅的对比要过规则 8（`CONTRAST` 会判）。
3. 同一页最多四色含纸（规则 3，`INK` 会判；`--mute` 不计入）。
4. 换页时**不要**整页反色，除非是章节幕或结尾。
5. 红色（或爆点色）不要用来做正文，只做编号、几何、单句强调。
6. `--mute` 只给 标签档的页码/标签（见规则 9）；信息文本用 `--fg` 或 `--alt`（`MUTE` 会判）。

体检工具自动查第 2、3、6 条，其余靠眼睛。
