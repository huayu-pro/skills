# 视觉系统

## 一句话

**用最少的元素，制造最大的尺度、张力与记忆点。**

不是"复古苏联风"。构成主义首先是一套**压缩信息**的方法：把内容压进一个由几何、方向、比例构成的结构里，让第一眼就能读懂立场。

---

## 它从哪来（知道这些，才能判断"像不像"）

1917 年之后，一批俄国先锋派认为架上绘画已经没用了。艺术家应当成为工程师，把形式、材料、印刷和生产组织起来，为新的社会造东西——海报、书封、纺织图案、舞台装置。

- 塔特林（Tatlin）：把艺术接到材料与结构上，《第三国际纪念塔》未建成但成了宣言。
- 李西茨基（Lissitzky）：把字变成图形，《用红楔击败白军》（1919）用一块三角形画完一场内战。
- 罗德琴柯（Rodchenko）：把照片剪开再拼起来，仰角、对角线、极端裁切都从他开始。
- 斯捷潘诺娃（Stepanova）：把几何放进织物与服装。

1932 年被禁，但它的语法经包豪斯、瑞士平面设计散进了整个现代视觉传达。

**一条重要的区别**：构成主义的斜线是**论点**，不是装饰。当年把整块构图压到对角线上，是在宣称"旧秩序的稳定对称结束了"。今天借用这个语法时，如果没有需要表达的方向和动势，斜线就只是噪音。

## 七条可执行法则

### 1. 一页一条主斜线

其余元素要么平行于它，要么严格水平/垂直。两条竞争的角度读起来是噪音。

**角度符号**：CSS 正角 = 左上到右下（╲），负角 = 左下到右上（╱）。`transform-origin` 必须是中心。写风格简报时同时写方向和符号，例如“左下到右上 −11°”。

**怎么判断**：把页面缩到 10% 大小，还看得出一个明确的运动方向吗？看不出来就是没有斜线，或者斜线太多。主斜线的面积、长边、竞争轴判据见 `composition.md`。

### 2. 几何只承担空间、方向、节奏

每个形状都要能回答：它在分隔什么、强调什么，或者把视线推向哪里。答不上来就删。

**允许的形状只有四种**：矩形、正圆/圆弧、楔形（三角形）、直线。加上它们的旋转。**没有**圆角、没有斜切倒角、没有曲线装饰。

### 3. 字体是结构，不是标注

标题要参与构图——压在色块边缘、沿斜带排、和几何咬合。判断标准：**把标题换成同字号的灰色方块，构图还成立吗？** 成立说明字只是"贴上去的"。

### 4. 极端尺度差

巨物与微字并置。中间尺寸是最没有力量的尺寸。
典型配比：158px 标题 / 19px 正文 / 13px 微字。**不要出现 40px 这种"中号"当标题。**

### 5. 面积不均

主色 50–70%，爆点 8–15%。平均分配等于没有重点。
**检查**：眯眼看页面，能不能说出"这块最重"？说不出来就是平的。

### 6. 硬边直角切割

唯二允许的曲线是正圆和圆弧。所有色块边缘必须是直的。
被画布裁掉一部分的巨物，比完整放在画面里的巨物更有压迫感。

### 7. 复古质感只做薄薄一层

纸张颗粒、网点、轻微套色偏移——这些只增加年代感，不得降低识别度。透明度已经烘焙在 PNG 里（约 10–12%），**不要写 CSS `opacity`**；PPTX 会把它拍平。

## 从海报到幻灯片的三处调整

海报可以只有一句话。幻灯片不行。所以这套 skill 在海报语法上做了三处让步：

| 海报 | 幻灯片 | 原因 |
|---|---|---|
| 标题可以被色块咬掉 | 只允许超出画布边缘 | PPT 没有容器裁切 |
| 整段竖排 | 只有标签竖排 | 正文竖排在投影上有阅读成本 |
| 文字极少（正文面积见规则 6） | 每页字数见规则 10 | 观众需要信息，不只是情绪 |

即便如此，**每页仍然只允许一个主张**。三条支撑是上限，不是目标。

## 和相邻风格的区别（别做串了）

| 风格 | 区别 |
|---|---|
| **瑞士国际主义** | 正交网格、常规宽度无衬线、冷静；构成主义用斜线、窄体、有火气 |
| **包豪斯** | 更教学化、更几何中性；构成主义有明确的社会立场和宣传性 |
| **风格派（De Stijl）** | 严格正交、只用原色、绝不允许斜线；构成主义几乎全靠斜线 |
| **粗野主义网页** | 只借了"粗糙"，没有借结构；构成主义的粗糙是有装配逻辑的 |

如果你做出的页面"很整齐但没有方向感"，那是瑞士风；如果"很响但没有结构"，那是粗野主义。构成主义要求两者同时在。

## 自检五问

做完一页，问自己：

1. 缩到 10% 看，有没有一个明确的方向？
2. 眯眼看，哪块最重？说不出就是平的。
3. 删掉所有文字，构图还成立吗？（不成立说明几何是装饰）
4. 标题和正文的字号比是多少？小于 3.5 就没有力量。
5. 这一页如果打印成黑白，还读得懂吗？（构成主义的原始媒介就是单色印刷）

## 与通用 PPT 规范的冲突（明确拒绝）

网上多数 PPT 规范是为了"不像 AI 生成的模板"写的。其中有四条与构成主义直接对立，照做会毁掉这套语言。逐条说明，免得以后有人"按规范"把它改回去。

| 通用规范 | 构成主义 | 为什么 |
|---|---|---|
| **同层并列必须等宽均分** | **拒绝**。必须面积不均，首栏按 `assets/rules.json` 的 `thresholds.balance.recipeFr` 起，下限是 `minRatio` | 等宽 = "并列 = 等价"。构成主义的读者要能一眼判断哪条最重要 |
| **禁止色条、满幅色块、侧边条** | **拒绝**。色带和满幅色块就是结构本身 | 那些规则针对的是"用装饰填补空白"；这里色块承担的是分隔、强调、指向 |
| **避免米色 / 奶油色背景** | **拒绝**。纸色是这套语言的物理来源 | 构成主义诞生于廉价纸张与两色油墨。白底会变成"现代办公风" |
| **禁止标题下的装饰线** | **部分接受** | 纯装饰的下划线确实没用；但 `.rule--pop` 这种 6px 短线是"标点"，不是装饰——它标记一段的结束 |

但它们背后的原则仍然成立：**每加一个元素，都要能说出它在分隔什么、强调什么、把视线推向哪里。** 说不出来就删。

## 去“AI 生成味”对照表

通用 PPT 规范要反过来用，但“一眼 AI”的模板感另有来源——不是色块和斜线，而是**重复、居中、均匀、无限兜底的干净**。逐条给处方：

| 症状（AI 生成的 PPT） | 构成主义处方 |
|---|---|
| 每页同一个构图，只换了文字 | 换骨架 family；相邻页不同族；`axisDeg` 正负交替制造镜像方向变化 |
| 标题永远居中，四周留白均匀 | 标题压边、左对齐压角；让巨物（圆/楔/数字）被画布边缘裁掉 |
| 均匀等距的三栏/四栏卡片 | 首栏吃掉份额（引导列配方），其余收窄成支撑；面积差就是立场 |
| 紫蓝渐变、默认科技蓝 | 两墨一纸：纸底 + 一深一亮两种实色油墨，全部来自主题 token |
| 圆角卡片 + 阴影 + 半透明蒙层 | 硬直角、无阴影；压字用实色带，或把蒙层烘焙进图片 |
| 纯白发亮的底色 | 纸色（米白/暖白）打底，加 `.grain` / `.halftone` 印刷层 |
| 图标带圆底、正文配 emoji | 只用矩形/正圆/楔形/直线四种形状；编号用 `.num` 窄体数字 |
| 页脚每页一模一样 | folio 形态轮换（规则 11 已自动判）；页脚是节奏器 |
| 所有元素都端端正正待在安全区里 | 展示字与巨物大胆出血；正文才收进安全区 |
| 每页都“讲道理”，没有一页压场 | 极端尺度差：留一页只放巨字或巨号数字，把情绪压出来 |

**为什么管用**：AI 味的本质是“无立场的整齐”——所有元素权重相同、所有页面结构相同。构成主义的每条法则都在制造**不均**：面积不均、尺度不均、方向不均。把“不均”做足，模板感自然消失。

## 构图判据

主斜线的面积/角度/竞争轴、四层面积、光学中心、阅读顺序、安全区、遮挡与留白，逐条写在 `composition.md`。这一页讲“为什么”，那一页讲“怎么判”。

## 工具能替你检查的部分

`scripts/validate.mjs` 把上面这些法则做成了判定，规则码与修法见 `troubleshooting.md`。但有三件事工具查不了，只能靠眼睛：

1. **这条斜线有没有意义**——它是论点还是随手一转。
2. **这个色块在分隔什么**——答不上来就是装饰。
3. **整份翻下来有没有节奏**——用联系表（`render.mjs --sheet`）一眼看。

## 视觉四层

一页的视觉是叠出来的，不是摆出来的。从下往上四层，缺一层画面就"薄"：

| 层 | 承担什么 | 用什么 | 面积 |
|---|---|---|---|
| **L1 底色** | 定调。观众第一眼看到的"纸" | `.slide` 的 `theme-*` 背景 | 45–65% |
| **L2 装饰层** | 动势与质感。斜带、巨圆、颗粒 | `.band` / `.sun` / `.wedge` / `.grain` | 15–30% |
| **L3 内容层** | 文字与图。读者真正要读的 | `.t-*` / `.meta` / `<img>` | 10–20% |
| **L4 强调层** | 一个爆点。只给最重要的一处 | `--pop` 的色块或一次 `fg-pop` 换色 | ≤10% |

**检查方法**：把页面盖住 L3（只留 L1、L2、L4），它应该仍然是一张成立的海报；再把 L3 露出来，它应该更清楚而不是更乱。
如果去掉文字就什么都不剩，说明 L2 只是装饰，没有承担结构。

## 动画：给观众一个读的顺序

动画在本项目里属于**转换器细节**，实现要点（preset 映射、XML 结构、spid 对应关系）已经独立到 `references/animation.md`。这里只留设计约束：


构成主义的动画只有一件事要做：**让观众按设计的顺序看**。所以动画是"揭示顺序"，不是"效果展示"。

### 该做的

| 顺序 | 对象 | 效果 | 理由 |
|---|---|---|---|
| 1 | 主斜带 / 楔形 | `wipe-up` / `wipe-down` | 先给出方向，观众的眼睛就知道往哪走；**扫入方向要和斜线的走向一致** |
| 2 | 巨圆 / 大色块 | `fade`（步 1） | 压住画面，建立尺度 |
| 3 | 标题 | `fade`（步 2） | 字最后落，落的时候画面已经稳了 |

### 不该做的

- **逐字打字机**：构成主义的字是"一块结构"，不是"一句话被念出来"。
- **旋转飞入、弹跳、缩放**：这套语言的动势来自构图，不来自元素运动。
- **每页都动**：一页三个对象已经是上限；连续三页全动画会让人疲劳。
- **点了才动**：全部用"上一动画之后"自动串联，演讲者不需要按遥控器。

### 怎么写（本项目）

```html
<div class="band"  data-anim="wipe-up" data-anim-step="0" …></div>
<div class="sun"   data-anim="fade"    data-anim-step="1" …></div>
<div class="t-hero" data-anim="fade"   data-anim-step="2" …>构成主义</div>
```

- 取值：`fade` / `dissolve` / `wipe-up` / `wipe-down` / `wipe-left` / `wipe-right` / `wedge` / `circle-in` / `circle-out`。
- `step` 越大越晚（每级 120ms）。首个 `clickEffect`，同页后续 `withEffect` —— 一次点击，整组依次揭示。
- 默认关闭：不写 `data-anim` 就没有任何动画，输出与以前完全一致。
- 编译时加 `--no-anim` 关掉；`--anim-mode=click` 让每个元素各点一次（与实证模板完全一致）。

### preset 编号

`wipe-up` 的 subtype 是 1 不是 4，写反方向会整体倒过来——具体表在 `references/animation.md`，是验证过的，不要凭 ECMA 文档猜。

> preset 映射、XML 结构与 spid 对应关系：`references/animation.md`。
