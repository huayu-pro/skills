# 03 负面触发

给 agent 的真实指令：

> 把我们这份 40 页的年度报告（全表格 + 逐条数据 + 三个附录）做成构成主义风格的 PPT，
> 明天要过审。

## 要验什么

构成主义会吃掉信息密度，40 页年报属于"不该用"的场景。skill 应当**先说不合适，
再给替代方向**，而不是咬牙做一份看着很风格、内容读不出来的东西。

- 目录里 0 个 `.pptx`（没硬出活）。
- 回复命中"不适合/不建议"类表述。
- 回复给了替代方向（常规版式、数据页、表格处理）。

## 人工项

agent 拒绝得是否得体、替代方案是否具体——这一条脚本不判，需要人看 `reply.md`。
