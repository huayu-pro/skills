# 01 正常产出

给 agent 的真实指令：

> 做一份 10 页的构成主义路演，主题是「城市里的夜间劳动者」，受众是品牌方评审，
> 15 分钟。子风格我给不出偏好，你定。

## 要验什么

- deck.html 结构完整、页数 ≥8、每页有 data-notes。
- 验证链真的跑了：`selfcheck` / `validate` / `audit-text` / `build` 全 exit 0。
- **文字真的可编辑**（pptx 里 ≥40 个 `<a:t>` run），形状是原生对象（≥20 个 `<p:sp>`）。
  截图贴图会让 run 数塌到个位数——这是"原生可编辑"承诺的唯一硬证据。
- 编译过程没有 FORBID。

## 判据

见 `run.mjs` 的 `CASES['01-normal']`。
